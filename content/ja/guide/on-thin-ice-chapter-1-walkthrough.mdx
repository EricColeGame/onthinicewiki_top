## 警察署：ランサムウェアによるロックアウトを解除する

チャプターは署内の混乱から幕を開けます。ケイト・グレイのデスクは、現在進行中のランサムウェア被害のため黄色い規制線テープで立ち入り禁止になっています。

この**On Thin Ice チャプター1 攻略**における最初の障害を突破する手順は以下の通りです：

1. ケイトのデスクの左下にある収納箱をタップして**チップリーダー**を入手します。
2. チップリーダーをコンピュータ画面の横にあるワークステーションのデスクに置きます。
3. モニターを確認すると、5桁の認証オーバーライドコードの入力を求められます。
4. インベントリ内のチップリーダーを詳しく調べます。太字で浮き彫りになっている5つの数字が確認できます：**63849**。
5. コンピュータのコンソールに **63849** を入力します。

端末のロックを解除すると、マーフィーの情報提供者であり「ハックソー」として知られる謎の人物が、人里離れた山小屋での銃撃戦の後、連絡を絶っていることが判明します。マーフィーとケイトは直ちに猛吹雪の中へと向かいます。

## 山小屋の外：除雪と侵入

ハックソーの山小屋に到着すると、マーフィーは弾痕を発見し、電話をかけても応答がありません。激しい吹雪によって通路は深い雪に埋もれ、中に入ることができません。

### 除雪機の組み立てと操作

正面ポーチへの道を切り開くには、私道近くに放置されている除雪機を修理する必要があります：

* 左側のフェンスの支柱付近にある**車輪**を拾います。
* ポーチの階段近くに半分埋もれている**ノズル**を拾います。
* 発電機の覆いのそばに置かれている**燃料缶**を回収します。
* 3つのパーツを壊れた除雪機に組み合わせます。

修理した除雪機をタップして雪を吹き飛ばします。雪を取り除くと、凍った地面の上に散らばった**金属製の数字**が現れます。

### 金属プレートパズル

金属製の数字を拾い、正面ドアのすぐ右側に取り付けられている木製ボードを調べます。下の段に記された計算の手がかりに従って、一番上の列に数字を配置する必要があります。

```
ボードの手がかりレイアウト:
上段のスロット: [ 4 ] [ 0 ] [ 8 ] [ 2 ] [ 7 ]
ロジック: 下段の木製プレートに示された合計値の一致。
```

タイルを正しく並べると、数字の配列 **40827** が導き出されます。山小屋ドアの電子キーパッドロックをタップし、**40827** を入力して中に入ります。

## 山小屋の内部：ハックソーの遺体と金庫

中に入ると、荒らされた部屋の床にハックソーが死亡しているのを発見します。部屋を徹底的に調査するため、遺体に触れる前にいくつか捜査手順を踏みます：

* ひっくり返ったマットレスを引きずり出して床を片付けます。
* エリアラグをめくって、緩んだ床板を露出させます。
* 窓の雨戸を開けて、暗い部屋に光を入れます。
* 吊るされている**布カーテン**を取り外します。
* 頭上のキッチン戸棚を開けて**金切鋸（ハックソー）**を取り、未完成の回路基板を確認します。

### ハックソーの遺体検証

被害者の遺体を詳しく調べます。注目すべきポイントが4つあります：

1. 胸ポケットに入っている空のスマートフォンケース。
2. 義足にある隠された機械的な継ぎ目。
3. 肌に刻まれた複数の特徴的なタトゥー群。
4. 右手の近くで握りしめられている小さな**シンボルストリップ**。

```
シンボルストリップの順番:
[ 矢印 ] -> [ ドクロ ] -> [ ハート ] -> [ 波 ]
```

### 床下の金庫とタトゥーの解読

戸棚から入手した金切鋸を使ってラグの下の緩んだ床板を切り、重いスチール製の金庫を持ち上げます。金庫のキーパッドは乾いた血で汚れており、操作部が見えなくなっています。

一度正面ポーチに出て、布カーテンをぬかるんだ水たまりに浸して**濡れた布**を作ります。再び山小屋に入り、ダイヤルを拭きます。

4桁のコードを導き出すには、ハックソーの体のタトゥーの中から、シンボルストリップに示された各アイコンの総数を数えます。

### タトゥーシンボルの内訳

| シンボル | 体の部位 | 総数 | 金庫の桁 |
| :--- | :--- | :--- | :--- |
| **矢印** | 左肩（3）、右前腕（4）、首（2） | **9** | 1桁目 |
| **ドクロ** | 胸（2）、左上腕（2） | **4** | 2桁目 |
| **ハート** | 左手 / 手首（1） | **1** | 3桁目 |
| **波 / 水** | 脇腹（3）、右肩（3） | **6** | 4桁目 |

綺麗になった金庫の鍵に **9416** と入力します。中から**手紙**、装飾用の**三角形**のセット、そして**ピッキングガン**を回収します。

当**On Thin Ice チャプター1 攻略**の手順に従えば無駄な行き来を防ぐことができます。これで施錠された裏ドアを開けるための道具が揃いました。

## 裏庭：消火と氷の階段パズル

ピッキングガンを装備して、山小屋の右側にある施錠されたドアを開けます。外に出ると悲惨な光景が広がっています。車両が氷の渓谷に激突し、激しく炎上しています。

```
裏庭のシーン配置:
[ パティオのグリル / タープ ] ------ [ 氷の階段パズル ]
         |                                |
[ 錆びた収納チェスト ]           [ 炎上する車両 / 死体 ]
```

### パティオでのアイテム回収

炎に近づく前に、まずはテラス周辺を探索します：

1. パティオのグリルから保護タープを取り外します。
2. **消火器**と**クリーニングオイル**のボトルを拾います。
3. グリルの横にある吹きだまりの雪を払いのけ、鍵のかかった金属製チェストを露出させます。
4. チェストの腐食した鍵穴にクリーニングオイルを注ぎ、後で鍵を使えるようにしておきます。

### 氷の階段パズルの攻略

燃えている車両に安全に近づくには、不安定な流氷を渡る必要があります。氷のブロックをタップしてスライドパズルを開始します。

目的は、氷のブロックを数字の順番にスライドさせて、安定した下り階段を作ることです。このパズルはスライドできるスペースが狭いため、多くのプレイヤーがつまずきやすいポイントとして挙げられています。

```
目標とする階段の並び:
スロット 1: ブロック [ 1 ]
スロット 2: ブロック [ 2 ]
スロット 3: ブロック [ 3 ]
スロット 4: ブロック [ 4 ]
スロット 5: ブロック [ 5 ]
バッファスペース: 上部や側面の退避スロットを使い、順番に関係ないブロックを一時待機させます。
```

### 車両の捜索手順

氷が安全な階段状に揃ったら：

* 消火器を車のエンジンと車内に向けて使い、炎を消し止めます。
* 残骸の横に倒れている組織のメンバー2人を調べ、**バール**と**レンチ**を入手します。
* 歪んで開かなくなった運転席のドアにバールを差し込み、こじ開けます。
* 助手席に手を伸ばし、**電話コード**を回収します。

## ハックソーのスマートフォンと郵便受けの解除

車の捜索を終えたら、ハックソーの隠されたデジタル通信ログを取り出すため、山小屋内に戻ります。この**On Thin Ice チャプター1 攻略**パートでは、複数の物理アイテムを連携させていきます。

```
修理の手順フロー:
レンチ -> 車椅子 -> 小さな鍵 -> オイルを塗ったチェスト -> ドライバー -> 義足 -> スマホ
```

1. 回収した電話コードを、ワイヤレス充電パッドの横にある壁のコンセントに差し込みます。
2. 部屋の隅にある壊れた車椅子を調べます。レンチを使って緩んだ車軸のボルトを締めると、**小さな鍵**が外れて落ちてきます。
3. 裏庭のパティオに戻り、オイルを塗った金属チェストに小さな鍵を差し込みます。**ドライバー**と追加の**三角形**のセットを回収します。
4. ハックソーの遺体に戻ります。ドライバーを使って義足のコンパートメントを留めているネジを外します。
5. 内部の空洞からバッテリー切れの**スマートフォン**を取り出します。
6. スマートフォンを通電したワイヤレス充電台の上に置きます。ケイトとマーフィーの短い会話の後、充電された端末を回収します。
7. 端末には顔認証がかかっています。画面をハックソーの顔にかざして生体認証セキュリティを解除します。

ロックが解除されたメッセージ履歴を読みます。ハックソーは正体不明の組織の工作員から脅迫を受けており、直近の補給物資が正面ゲートの郵便受けに直接届けられたことがわかります。

山小屋正面の私道に出ます。セキュリティの高い郵便受けをタップし、ロック解除されたスマートフォンを使ってデジタルの解除コードをスキャンします。蓋が開き、最後の**三角形**のセットと暗号化された**チャート**を入手できます。

## 戸棚：三角形パズルと隠し金庫

山小屋内に戻り、開いている壁の吊り戸棚に注目します。電気回路基板を完成させるために必要なすべての三角形タイルが揃いました。

### 三角形パズルの仕組み

集めたすべての三角形を、戸棚のボードの空いているスロットにはめ込みます。目標は、左側の入力ノードから右端にある黄色の受け取り三角形までパルス電流を通すことです。

* 電流が三角形を通過するたびに、そのタイルが時計回りに90度回転します。
* タイルの回転によって次のノードへの接続が途切れないようにルートを計画します。
* 光っている隣接する三角形を順番にタップして、ボード全体にパルスを安全に誘導します。

電気ループを完成させると隠しラッチが作動し、印刷された印画紙（**写真**）が排出されます。

### ハックソーのハードドライブの発見

これで、チャプター最後の謎を解くために必要な3つの重要アイテムがすべて揃いました：

1. **手紙**（床下の金庫から）
2. **チャート**（屋外の郵便受けから）
3. **写真**（戸棚の回路パズルから）

山小屋の壁にあるマークされた掲示板に近づきます。指定された枠線に合わせて、手紙、チャート、写真をピンで留めます。

3つの書類のグリッドポイントを揃えると、羽目板の奥にある隠し壁金庫の解除レバーが現れます。金庫が開き、ランサムウェアの復号鍵が入ったハックソーのバックアップ用外付けハードドライブが出現します。

遠くからサイレンの音が響き渡る中、ケイトとマーフィーは証拠を確保し、チャプター1は幕を閉じます。当**On Thin Ice チャプター1 攻略**を活用することで、チャプター2で待ち受けるさらに難解なパズルに向けて、貴重なヒントスターを温存しておくことができます。

## よくある質問（FAQ）

### ハックソーの山小屋にある金庫の暗号コードは何ですか？
山小屋の床下にある金庫の暗号は **9416** です。メモ用紙に描かれた順序（矢印9個、ドクロ4個、ハート1個、波6個）に従い、ハックソーの体にあるタトゥーのシンボルを数えることで解くことができます。

### 山小屋の前の郵便受けはどうやって開けますか？
郵便受けをピッキングしたり無理やりこじ開けたりすることはできません。ハックソーのスマートフォンをデスクの充電台で充電し、遺体の顔にかざしてFace IDでロックを解除した後、配達を確認するテキストメッセージを読み、インベントリにスマートフォンを持った状態で郵便受けをタップしてデジタルロックを解除する必要があります。

### パティオのチェストにクリーニングオイルが使えないのはなぜですか？
多くのプレイヤーが最初に雪を払いのけるのを忘れてしまう傾向があります。インベントリのクリーニングオイルを使う前に、グリルの横にある雪の山をタップして錆びた留め金を露出させる必要があります。オイルを塗った後も、屋内の車椅子をレンチで修理して手に入る小さな鍵が必要です。

### このチャプターでさらにサポートが必要な場合はどこを見ればいいですか？
アイテムを見落としたり、捜査中に行き詰まった場合は、整理された当**On Thin Ice チャプター1 攻略**を参照すれば、除雪機のノズルから戸棚の三角形タイルまで、すべての必須ツールを正しい手順で見つけることができます。
