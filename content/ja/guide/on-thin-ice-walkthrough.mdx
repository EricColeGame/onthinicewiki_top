## 第1章の概要：警察署の破綻と森のロッジ

物語は、サイバー攻撃を受けて立ち入り禁止の規制線テープが張られたケイト・グレイのデスクから始まります。情報屋のハックソー（Hacksaw）に会う前に、作業環境を復旧させて最初の突破口を開く必要があります。

```
デスク -> チップリーダー (63849) -> 情報屋のロッジ -> 除雪機の組み立て -> キーパッド (40827)
```

1. **ケイトのデスクを調べる:** 床の証拠品ボックスの中にあるチップリーダーを拾います。
2. **端末にアクセスする:** モニター横のデスク上にリーダーを置きます。チップリーダーをよく観察すると、太字の数字列「**63849**」が確認できます。この5桁のコードを端末に入力し、PCのロックを解除します。
3. **ハックソーのロッジに到着:** 激しい降雪の中、ケイトとマーフィーは人里離れた隠れ家に到着します。銃撃戦の通報があった後、ハックソーは電話に出なくなっていることが判明します。
4. **除雪機を修理する:** 深い吹きだまりに阻まれて玄関ポーチまで進むことができません。前庭に散らばっている3つのパーツを回収します：
   * **ホイール（車輪）:** 左側のフェンス付近。
   * **ノズル:** 通路の脇。
   * **燃料キャニスター:** ポーチの階段付近。
5. **雪を払って道を作る:** ホイール、ノズル、燃料キャニスターを除雪機に取り付けます。庭全体に除雪機を走らせ、吹きだまりを完全に除去します。
6. **ロッジのキーパッドを解読する:** 雪の下から現れた金属製の数字プレートを拾います。右側の壁にあるボードの枠にはめ込みます。最上段の数字を正しく並べ替えると、「**40827**」という数列が現れます。ドアのキーパッドに「**40827**」を入力してロッジに入室します。

| 場所 | 発見したキーアイテム | 必要なアクション | 結果のコード / 展開 |
| :--- | :--- | :--- | :--- |
| 警察署 | チップリーダー | リーダー外装の太字の数字を読む | ケイトのPCをロック解除 (`63849`) |
| ロッジの前庭 | ホイール、ノズル、燃料 | 除雪機にパーツを組み立てる | 深い雪の吹きだまりを除去 |
| 玄関ポーチのボード | 金属製の数字プレート | 最上段の数字を正しい位置に配置 | ドアのキーパッドコード (`40827`) |

この**On Thin Ice 攻略ガイド**の手順に従うことで、当て推量を省き、序盤の捜査でゲーム内通貨を節約できます。

## 情報屋の金庫を解錠：タトゥー解読パズル

ロッジの内部では凄惨な光景が広がっています。情報屋は何者かに射殺されており、他殺であることは明白です。室内を捜索し、隠された収納スペースを見つけ、床に設置された頑丈な金庫を開ける必要があります。

```
窓を開ける -> 床板を切る (金切りのこ) -> 金庫を洗う -> タトゥーの数を数える -> 金庫を解錠 (9416)
```

まずは散らかった室内を片付けます。乱れたマットレスを脇に押しやり、フロアラグを巻き上げます。窓の鎧戸を開けて、暗い室内に自然光を取り入れます。窓枠から布のカーテンを回収します。壁のキャビネットを開けて、施錠されたミニゲームの区画を確認し、金属製の金切りのこを入手します。

ハックソーの遺体にある4つの注目ポイントを調査します：
* スマホケースを確認し、スマートフォンが持ち去られたか隠されていることを把握します。
* 彼の義足を調べ、固定されたパネルがあるのを確認します。
* 手の近くに落ちている紙のシンボル片を回収します。
* 体のタトゥーを詳しく観察します。

ベッド近くの緩んで軋んでいる床板に金切りのこを使い、乾いた血痕で覆われた鉄製金庫を露出させます。外に出て雪解けの水たまりで布カーテンを濡らし、室内へ戻って金庫のダイヤルから血を拭き取ります。

本**On Thin Ice 攻略ガイド**で解説するように、この金庫を開けるには、紙片のシンボルとハックソーの皮膚にある対応するタトゥーを照合して割り出す4桁の暗証番号が必要です。

| 紙片のシンボル | 見た目の特徴 | 体のタトゥーの位置 | 合計数（金庫の数字） |
| :--- | :--- | :--- | :--- |
| **矢印** | 尖った方向を示す矢印 | 腕、首、胸部 | **9** |
| **ドクロ** | 定番の頭蓋骨アイコン | 前腕と胴体 | **4** |
| **ハート** | 解剖学的/心臓の形のハート | 胸の上部と肩 | **1** |
| **波** | 水流・波のさざなみ | 手首と鎖骨付近 | **6** |

金庫のダイヤル錠に「**9416**」を入力します。中から以下のアイテムを入手できます：
* 機密の手書きメモ。
* カラフルな三角タイルの束。
* プロ仕様のピックガン。

## 裏庭の探索：炎上する車と氷の階段パズル

ピックガンを使ってロッジの頑丈な裏ドアの鍵を開けます。外へ出ると、炎に包まれた車と雪の上に倒れたギャングの構成員たちという、混沌とした犯行現場が広がっています。

```
火を消す -> 遺体を捜索 (バールとレンチ) -> 氷の階段を解く -> 車のドアを開ける
```

安全に車両を調べる前に、工具を集めて火を消す必要があります：
1. 屋外グリルに掛かっている防護シートを剥がし、**消火器**と**洗浄油**の缶を見つけます。
2. 階段脇の雪を払い、錆びついたロックボックスを見つけます。固着したラッチに洗浄油を直接スプレーし、後で開けられるように準備しておきます。
3. 「氷の階段」と名付けられた凍った岩棚のパズルに向かいます。

当**On Thin Ice 攻略ガイド**のこの段階において、多くのプレイヤーが氷の階段のスライドギミックで足止めを食らいます。目的は、数字が書かれた氷のブロックをグリッド上でスライドさせ、対応する数字のくぼみにぴったり収めることです。

```
[目標 1] <--- バッファレーンを使ってブロック1をスライド
[目標 2] <--- 予備のバッファタイルを利用して障害物を回避
[目標 3] <--- 最後の配置を決めて岩棚を渡れるようにする
```

渡りきったら、消火器を使って車両の火を消し止めます。残骸の近くにある2つの遺体を調べ、重厚な**バール**と調節可能な**レンチ**を入手します。

| 障害 / 状況 | 必要なアイテム | 入手場所 | 直後の効果 |
| :--- | :--- | :--- | :--- |
| 激しく燃える車の火 | 消火器 | グリルのシート下 | 車の火を消火 |
| 錆びたボックスの留め金 | 洗浄油 | グリルのシート下 | 頑固な錆を溶かす |
| 崩落した岩棚 | 氷のブロック | 氷の階段パズル | 安定した足場を形成 |
| 歪んだ車のドア | バール | 車両付近の遺体 | スマホの充電コードを入手可能に |
| 壊れた車椅子 | レンチ | 車両付近の遺体 | 小さな真鍮の鍵を入手 |

バールを使って変形した車の助手席ドアをこじ開け、予備のスマホ充電コードを回収します。

## ハックソーのスマホのロック解除と郵便ポストの謎

引き続き**On Thin Ice 攻略ガイド**を進めましょう。ロッジの中に戻り、電子機器を組み立ててハックソーの生体認証セキュリティを突破します。

```
車椅子を直す -> 鍵を入手 -> ボックスを開ける -> 義足のネジを外す -> スマホを充電 -> 顔認証でロック解除
```

室内の出入口付近にある破損した車椅子にレンチを使います。ボルトを締め直すと、**小さな鍵**が外れて手に入ります。燃えた車の場所まで外に戻り、油を差したロックボックスに小さな鍵を使用します。中から精密**ドライバー**と2つ目の三角タイルのセットが見つかります。

ロッジに戻り、ドライバーを使ってハックソーの義足のネジを緩めます。隠しスペースの中に、バッテリーが切れた彼のスマートフォンが入っています。

1. **デバイスの充電:** 充電コードを壁のコンセントに差し込み、カウンターにあるワイヤレス充電スタンドに電源の切れたスマホを置きます。
2. **会話パート:** バッテリーが起動可能な残量まで充電される間、ケイトとマーフィーはシンジケートについての会話を交わします。
3. **生体認証のバイパス:** スマホには顔認証ロックが掛かっています。インベントリからスマホを選択し、ハックソーの顔に向けてロック画面を解除します。
4. **メッセージログの確認:** メッセージスレッドを確認します。ログにはランサムウェア組織からの直接的な脅迫文とともに、屋外の郵便ポストに重要な荷物が残されているという確証が残されています。

ロッジ正面の車道へと戻ります。ロックを解除したスマホを使って、スマートポストにデジタル信号コードを送信します。フタを開けて、3つ目の**三角タイル**と暗号化された**地理チャート**を回収します。

## トライアングルパズルと隠し金庫の発見

金庫、庭のロックボックス、郵便ポストからすべての三角タイルを集めたら、ロッジ内の壁キャビネットに戻ります。ピースをはめ込んでトライアングル（Triangulate）パズルを起動します。

```
三角形をはめる -> 導管を回転させる -> 電気の点を導く -> 犯行現場の写真を回収
```

このミニゲームでは、左側の電源から右端にある黄色の目標三角形まで電流を誘導する必要があります。電荷がタイルを通過するたびに、そのタイルは時計回りに90度回転します。

* **プレイヤーコミュニティの情報**によると、終点である黄色の三角形から逆算して考えると、どの向きで接続すべきかをイメージしやすくなります。
* 電流が行き止まりの回路に入らないよう注意してください。タイルの角度をリセットせざるを得なくなります。

電流を目的地まで無事に導くと回路が繋がり、キャビネットの隠し仕切りから重要な**写真**が落ちてきます。

| 手がかりアイテム | 入手先 | 配置場所 | 最終的な発見 |
| :--- | :--- | :--- | :--- |
| **手紙** | 情報屋の床下金庫 | 証拠ボードにピン留め | 暗号の配置パターンを解読 |
| **チャート** | 前庭の車道ポスト | 証拠ボードにピン留め | ファイルの座標ノードをマッピング |
| **写真** | キャビネットのパズル | 証拠ボードにピン留め | 解錠トリガーを完成させる |

ロッジの壁にある捜査用ピンボードに、手紙、チャート、犯行現場の写真を留めます。これら3つのピースを正しく並べると、壁のくぼみに隠されていた機械仕掛けの金庫が現れます。ハックソーが持っていたランサムウェアの証拠が入った暗号化ハードドライブを取り出します。

この**On Thin Ice 攻略ガイド**における決定的なマイルストーンを越えると、第1章のドラマチックなクライマックスへと直結し、シンジケートの内通者を追う捜査チームの次なる展開が開かれます。公式ニュースや対応プラットフォーム、今後のアップデートについては、[Haiku Games 公式ポータル](https://www.haikugames.com)でミステリーアドベンチャーの全ラインナップをご確認いただけます。

## Adventure Escape Mysteries プレイのプロ直伝のヒント

ケイト・グレイが挑む事件は、ポイント＆クリック型パズルのベテランプレイヤーにとっても手応えのある難問ばかりです。この**On Thin Ice 攻略ガイド**を参考にしながら、細かな環境の変化に気を配ることで、よりスムーズかつ達成感のあるプレイを楽しめます。

* **画面の隅々まで丹念に調べる:** シーンの外枠や境界線付近をくまなくタップ（またはクリック）しましょう。レンチ、洗浄油、金属プレートなどのインベントリアイテムは、雪景色や瓦礫の背景に溶け込んで見落としがちです。
* **手がかりノートを用意する:** ゲーム内のインベントリにも手がかりは記録されますが、数字（タトゥーの数やチップリーダーのシリアルなど）を手元にメモしておくと、画面の切り替え頻度を減らせます。
* **方向の手がかりを見逃さない:** 遺体、壁のパネル、電子機器を調べるときは、矢印の向きや色分けされたインジケーターに注意してください。これらは多くの場合、複数桁の暗証番号の入力順序を示しています。
* **パズルのスキップは温存する:** 「氷の階段」や「トライアングル」のようなパズルは初見では難しく感じるかもしれませんが、規則的なパターンが存在します。後の章で登場する複雑な論理パズルのために、ゲーム内の星（ヒントスター）は温存しておきましょう。

## よくある質問（FAQ）

### On Thin Ice 攻略において、ロッジの金庫の暗証番号は何ですか？
ロッジの床下金庫の暗証番号は「**9416**」です。外の雪解け水で布カーテンを濡らし、金庫扉の血痕を拭き取った後、シンボル紙片とハックソーのタトゥーを照合して割り出します（矢印9個、ドクロ4個、ハート1個、波のシンボル6個）。

### キーパッドが反応しない場合、ロッジの玄関ドアはどうやって開ければいいですか？
玄関ドアを開けるには、雪の吹きだまりに埋もれている金属製の数字プレートを見つける必要があります。まず、ホイール、ノズル、燃料缶を集めて除雪機を修理します。除雪機で雪を吹き飛ばして数字プレートを拾い、壁のボードに並べて「**40827**」を作ったら、キーパッドにそのコードを入力します。

### 第1章の三角ピースはどこにありますか？
キャビネットのパズルに必要な三角タイルのセットは、以下の3か所に分かれて配置されています：
1. 軋む床板の下にある、血で汚れた床下金庫の中（コード: 9416）。
2. 炎上する車の近くにある、錆びついた金属製ロックボックスの中（洗浄油と車椅子から外した小さな鍵で開錠）。
3. 前庭の車道にある郵便ポストの中（ハックソーの充電済みスマートフォンでロック解除）。

### パスコードなしでハックソーのスマホのロックを解除するにはどうすればよいですか？
充電コードをワイヤレスパッドに繋いでスマホを充電した後、インベントリからスマホを選択してハックソーの顔を直接タップします。端末は顔認証セキュリティを使用しているため、自動的にSMSの通信履歴やポストの送信機能にアクセスできるようになります。
