## チャプター1攻略：警察署のロックダウンからハックソーの山小屋まで

オープニングチャプターは、冒険全体を特徴づける環境推理システムの濃密なチュートリアルとして機能しています。以下は、チャプター1を攻略するために必要な手順の体系的な解説です。

```
警察署端末 -> ハックソー宅の敷地 -> 山小屋内部 -> 炎上した車の外周 -> 三角測量金庫
```

### 1. ランサムウェアに侵された端末の復旧
規制線が張られたケイトの警察署デスクに到着すると、通常のシステムアクセスはランサムウェアのロックにより遮断されています。

*   デスクに隣接する証拠ボックスの中から、単体の**チップリーダー**を見つけます。
*   チップリーダーをモニターの横にあるケイトのワークステーションに直接配置します。
*   チップリーダーのシリアルプレートを確認します。太字で示された数列を特定します：**63849**。
*   端末のコンソールに**63849**を入力してステーションのロックアウトを解除し、作戦指令レポートを取得します。

### 2. ハックソーの山小屋前の雪だまりの除去
激しい銃撃戦の報せを受け、ケイトとマーフィーは情報提供者ハックソーの辺ぴな山小屋に到着します。厚い雪の壁が入口を塞いでいます。

*   庭の周囲を探索し、3つの機械パーツ（**ホイール**、**ノズル**、**燃料缶**）を回収します。
*   これら3つのアイテムを庭に放置されている壊れた除雪機に組み合わせます。
*   修理した除雪機を起動して雪だまりを除去すると、散乱した**金属の数字**が見つかります。
*   ポーチの右側にあるナンバーボードを調べます。バラバラの金属の数字を上部の溝に並べ替え、数列を明らかにします：**40827**。
*   山小屋の入口にあるキーパッドに近づき、**40827**を入力して強化ドアを開きます。

| ステップ | 実行するアクション | 使用ツール / 入力 | 解答 / 取得コード |
| :--- | :--- | :--- | :--- |
| **1** | チップリーダーの初期化 | 証拠ボックス / ワークステーション | コード：**63849** |

## 鑑識と金庫破り：ハックソーの秘密を暴く

荒らされた山小屋の内部に入ると、空気感は一気に暗転します。ハックソーは銃撃戦で死亡しており、彼の遺体と身の回りの遺品だけが唯一の捜査の手がかりとなります。

### 床下金庫の発見
山小屋内部の証拠を確保するための手順は以下の通りです：

1.  床のマットレスとラグを動かし、緩んだ床板を見つけます。
2.  窓を開けて外の光を取り込み、吊り下がっている**布のカーテン**を確認します。実用的な用途のために引き裂いて入手します。
3.  キッチンのキャビネットを調べ、手持ちの**金切りのこ（ハックソー）**を確保します。
4.  破損した床板に金切りのこを使用して、乾いた血痕で覆われた重い金属製金庫を取り出します。
5.  庭に戻り、溶けた雪の水たまりで布のカーテンを濡らしてから戻り、金庫のダイヤルロックから血を拭き取ります。

### タトゥー暗号の解答
山小屋の内部で、矢印、頭蓋骨、ハート、海の波という4つの異なる絵文字が印刷された細長い紙片が見つかります。ハックソーの遺体を調べると、腕、首、胴体に刻まれた数々の犯罪的・軍事的なタトゥーが確認できます。

| 絵文字シンボル | 体のタトゥーの位置 | 合計数（数字） |
| :--- | :--- | :--- |
| **矢印** | 前腕、鎖骨、胸上部、指の関節 | **9** |
| **頭蓋骨** | 上腕二頭筋、肩甲骨、手首 | **4** |
| **ハート** | 前腕の内側 | **1** |
| **波** | 肋骨付近、下腹部、首 | **6** |

金庫にコード**9416**を入力すると扉が開き、**ロックピンガン**、重要な**手書きの手紙**、そして後半のパズルで必要となる装飾用の**三角ピース**を入手できます。

```
シンボルストリップの順序： 矢印 -> 頭蓋骨 -> ハート -> 波
タトゥーのカウント：        9   ->   4   ->   1   ->   6
金庫解除PIN：              9416
```

## 複雑なロジックの攻略：氷の階段と三角測量パズル

静的な観察だけでなく、**on thin ice game**にはプレイヤーの計画力とルート構築力が試されるダイナミックな空間パズルも組み込まれています。これらの難関はチャプター1の終盤に連続して登場します。

### 氷の階段スライドパズル
山小屋の裏口でロックピンガンを使用すると、逃走用の車が炎上している中庭に出ます。火を消す前に、消防器具が保管されている上層のテラスに到達しなければなりません。

凍りついたテラスを調べると、ミニゲーム「**氷の階段**」が始まります。滑りやすい足場の上で番号のついた氷のブロックをスライドさせ、対応する番号のスロットに収める必要があります。

*   **基本ルール**：ブロックは障害物、壁、または他のブロックに衝突するまで止まりません。
*   **クッションブロック**：番号のない補助ブロックを人工的なバンパーとして活用し、番号付きブロックの勢いを止めます。
*   **攻略の手順**：小さい番号のルートを塞いでしまわないよう、まず最も大きい番号（下のスロット）から固定していきます。

パズルを完了すると、グリルエリアから**消火器**と**洗浄油**を入手でき、車両の火を消して倒れた銃撃犯から**レンチ**と**バール**を回収できるようになります。

| 入手アイテム | 入手場所 | 使用対象 |
| :--- | :--- | :--- |
| **洗浄油** | パティオのグリルのカバー下 | 錆びた屋外のロックボックス（腐食を除去） |
| **消火器** | 上層テラスの保管場所 | 裏庭の炎上している車両 |
| **バール** | 武装した襲撃者の遺体 | 開かない車のドア（充電ケーブルを入手） |
| **レンチ** | フェンス付近の襲撃者 | 壊れた車椅子の車輪（ロックボックスの鍵が落下） |
| **小さな鍵** | 車椅子のホイールリム部分 | 錆を落とした庭のロックボックス（ドライバーを入手） |
| **ドライバー** | 解錠された庭のボックス | ハックソーの義足にある隠しコンパートメント |

### ハックソーのスマートフォンと三角測量パズル
ドライバーを手に入れたら、ハックソーの義足に組み込まれた秘密のコンパートメントをこじ開け、バッテリーが切れたスマートフォンを回収します。

1.  車の充電ケーブルを山小屋のワイヤレス充電マットに接続します。
2.  スマートフォンの電源を入れ、ハックソーの顔に画面を向けて顔認証ロックを解除します。
3.  脅迫メッセージの履歴を読み、外の郵便ポストへの配達に関する言及を確認します。
4.  スマートフォンの認証シグナルを使用して表の郵便ポストを解錠し、残りの**三角ピース**と**地形図**を回収します。
5.  キャビネットの内部に戻り、すべての三角ピースをはめ込んで「**三角測量パズル**」を開始します。

三角測量パズルでの目的は、左側のスタートノードから右端の黄色いターゲット三角形まで電気パルスを導くことです。電気スパークが三角形に入るたびに、そのタイルは**時計回りに90度回転**します。

```
[スタートパルス] -> 三角ノードA（90°回転）
                -> 三角ノードB（90°回転）
                -> 三角ノードC（90°回転） -> [黄色いゴールノード]
```

効率的に解くには、終点の黄色いゴールから逆算してルートを辿ることです。パルスが突入した際の必須の90度回転を考慮に入れながら、パルスが到達した瞬間に各三角形がどの向きになっていなければならないかを割り出します。グリッドを解くと、証拠写真のロックが解除されます。写真、地形図、手紙を書斎の壁で組み合わせることで、ハックソーの暗号化されたハードドライブの封印が解かれ、チャプター1は無事終了となります。

## 『On Thin Ice』を攻略するための必須捜査ストラテジー

**on thin ice game**を初めてプレイする人は、基本的なアイテムの見落としや手がかりの読み間違いでつまずいてしまいがちです。規律ある捜査習慣を身につけることで、パズルのスキップに貴重なスターを浪費せずに済みます。

### 1. すべてのシーンを3巡して探索する
ケイトが新しいエリアに入ったら、必ず目的を分けた3巡の探索を行ってください：
*   **落ちているアイテムの確認**：床の破片、開いた容器、結び目が解かれたカバーなどをタップします。
*   **固定具の確認**：一般的な脱出ツール（ドライバー、レンチ、バール）に対応する物理的な固定具（ネジ、錆びた南京錠、こじ開けられそうな板など）を探します。
*   **テキストとシンボルの確認**：数字、普段見かけない模様、特徴的な落書きはすぐにメモを取ります。**on thin ice game**において、背景に見られる数字が単なる飾りであることはほぼありません。必ず直後に出現する南京錠やキーパッドに直結しています。

### 2. 空間パズルはチェスの詰将棋のように考える
「氷の階段」のようなスライドブロックのシークエンスでは、目的のないむやみなタップは命取りになります。氷のブロックが画面を横切ると、別のラインの配置が崩れてしまうことがよくあります。
*   ピースを1つ動かす前に、各ブロックの最終的な停止位置を頭の中で描きます。
*   どのタイルが自然なストッパー（角、壁際など）として機能するかを見極めます。
*   補助ブロックを取り出せなくなる角に押し込んではいけません。他のピースの進路を変えられるよう、可動ブロックは中央のレーンに残しておきます。

## コミュニティで報告されている難所と不具合の回避策

プレイヤーフォーラムやモバイルパズルコミュニティにおける体験談から、**on thin ice game**で捜査官たちがつまずきやすい代表的なポイントが判明しています。

| 報告された問題 | 根本原因 | プレイヤー検証済みの解決策 |
| :--- | :--- | :--- |
| **スマートフォンの顔認証が認識されない** | 被害者の顔に対するタップ判定のズレ | スマートフォンのアイコンを胸部ではなく、目や鼻の領域に正確にドラッグする。 |
| **錆取りが反応しない** | 油を差す前に鍵を使おうとしている | まず洗浄油を使用して酸化を溶かす必要があります。表面を処理するまで鍵は鍵穴に収まりません。 |
| **タトゥーのカウント数が合わない** | 見えにくい線画の見落とし | コミュニティの報告によると、胴体下部の波の模様は輪郭線に溶け込みやすいため、画面の明るさを上げて左腰を再確認してください。 |
| **除雪機が組み立てられない** | パーツを取り付ける順序の間違い | ホイールと排出ノズルが機械的に装着された後に、燃料を注ぐ必要があります。 |

暗い屋内の環境を探索する際は、デバイスの画面の明るさを少し上げておくことで、車椅子の構造部に埋め込まれた小さな鍵のような細かなインタラクト対象を見逃さずに済みます。

## 『On Thin Ice』に関するよくある質問（FAQ）

### 『On Thin Ice』チャプター1の金庫の暗証番号は何ですか？
ハックソーの山小屋内にある金庫の暗証番号は**9416**です。紙片のシンボル順（矢印、頭蓋骨、ハート、波）と、ハックソーの遺体に彫られたタトゥーを照合することで導き出せます。一致する絵文字を数えると、矢印が9個、頭蓋骨が4個、ハートが1個、波が6個となります。

### キャビネットのパズルに使う三角ピースはどこにありますか？
三角ピースはチャプター1の2箇所の異なる場所から入手します。1組目はコード**9416**を入力した後の血痕のついた床下金庫の中から手に入ります。最後のピースはハックソーの庭の郵便ポストの中に鍵がかかっており、スマートフォンの電源を入れてポストのデジタル受信部をスキャンした後にのみ開けることができます。

### 『On Thin Ice』は単体作品としてプレイできますか？
はい。物語の中でケイト・グレイが過去にエコー・ベイで遭遇したトラウマ的な事件への言及があり、マーフィー刑事との人間関係も進展しますが、事件自体は完全に独立して完結しています。過去のAdventure Escapeシリーズをプレイしていなくても、**on thin ice game**から直接プレイを開始し、混乱することなくシンジケート捜査のストーリーを楽しむことができます。
