## 序盤の難関パズル徹底解説（ステップ別解答）

『On Thin Ice AE Mysteries』を進める中で登場する複数段階のコードパズルは、細部への綿密な注意が求められます。手がかりは遺体や機械のシリアルナンバー、周囲の調度品に直接組み込まれているため、手順を飛ばしたり当て推量で入力したりしても突破は困難です。

### 1. 警察署のコンピューターと山小屋のキーパッド解錠

ケイトのデスクで、チップリーダーをコンピューター端末に接続します。リーダーのケース表面に刻印されたシリアル番号を確認すると、太字で書かれた5つの数字 **63849** が見つかります。この数字を入力することで、ケイトのPCのランサムウェア画面をバイパスできます。

雪に覆われた山小屋に到着したら：
- 車道に散らばっている交換用の車輪、ノズル、燃料缶を回収します。
- 動かなくなっている除雪機にパーツを取り付け、入り口を塞ぐ雪山を除去します。
- 散らばった金属製の数字プレートを拾い、看板の枠に並べます。
- 上段のレールに沿って数字をスライドさせ、組み合わせ **40827** を導き出します。
- 山小屋の電子ドアロックに **40827** と入力して内部に侵入します。

### 2. 情報提供者の血塗られた金庫の解読

山小屋に入ったら、マットレスと絨毯をめくって切れ目の入った床板を見つけます。クローゼットにある金切りのこを使って床板を切断してください。鍵のかかった金庫を取り出したら、カーテンの布切れを外の雪解け水で濡らし、テンキーにこびりついた血痕を拭き取ります。

金庫の暗証番号を割り出すには、ハックソーの手が握りしめているシンボルペーパーを、彼の体に刻まれたタトゥーの数と照らし合わせます。

| シンボルの手がかり | 体のタトゥーの数 | 導き出される数字 |
| :--- | :--- | :--- |
| **矢印** | 腕と胴体全体でカウント | **9** |
| **ドクロ** | 肩と胸元でカウント | **4** |
| **ハート** | 肩に1つだけ彫られている | **1** |
| **波** | 前腕のバンド部分でカウント | **6** |

**9416** と入力すると金庫のラッチが開き、ロックピックガン、幾何学模様の三角形パーツ3つ、そして緊急の警告メモを入手できます。

```
コード計算の内訳:
[矢印: 9] + [ドクロ: 4] + [ハート: 1] + [波: 6] = 暗証番号 9416
```

### 3. 氷の階段スライディングブロックの謎解き

裏口の鍵を開けると、逃走車が衝突炎上しているのが見えます。火元にたどり着く前に、滑りやすい裂け目の上に安定した足場を作らなければなりません。凍った氷のブロックをタップして、スライディングブロックパズルを開始します。

| 移動ステップ | 対象ブロック | 移動方向 | 目的 |
| :--- | :--- | :--- | :--- |
| **フェーズ1** | 最上段ブロック #1 | 空きスペースへ右スライド | 垂直方向の通路を開放 |
| **フェーズ2** | 中央ブロック #3 | 一番下のスロットへ下移動 | 下部の土台を形成 |
| **フェーズ3** | 番号付きブロック #2 | 左にスライド後、下へ移動 | 昇順のステップ2として固定 |
| **フェーズ4** | 番号付きブロック #4 | 上、右へ動かし、下へ落とす | 順番通りの階段ブリッジを完成 |

足場が完成したら、消火器で車両の火を消します。車内の人物を調べてレンチと鉄製バールを回収し、車のドアをこじ開けてモバイル用充電ケーブルを入手します。

### 4. 三角形回路（トリアングレート）と隠し壁金庫

小屋の中に戻り、壊れた車椅子にレンチを使って小さな鍵を回収します。外の工具箱を開けてドライバーを取り出し、ハックソーの義足を開いてバッテリー切れのスマートフォンを取り出します。

電話を充電したら、カメラレンズをハックソーの顔に向けて顔認証ロック（Face ID）を解除します。SMSの受信トレイを確認すると、配達員が表の郵便ポストに重要書類を届けていたことが判明します。スマホのワイヤレスリンク機能を使って郵便受けを解錠し、残りの三角形パーツと建築設計図を入手しましょう。

集めたすべての三角形を寝室のキャビネットのパズルボードにはめ込みます。トリアングレートパズルを解く手順：
- 点滅する電気のパルスを、一番右側にある黄色の端子へと誘導します。
- 電流が三角形に入るたびに、そのノードは時計回りに90度回転します。
- 次のパルスが出口のワイヤーと一直線になるよう、何もない頂点を経由するルートを計算します。
- 回路を完成させると隠し引き出しが開き、古いアーカイブ写真が手に入ります。

手紙、構造設計図、写真を証拠ボードに貼り付けると機械式の壁金庫が作動し、破損を免れたハックソーの外付けハードドライブを回収できます。

## 上級者向け戦略とリソース管理のコツ

『On Thin Ice AE Mysteries』の熟練プレイヤーは、ヒント用のスターを安易に消費するのではなく、壁画やメッセージログのスクリーンショットを撮っておくことを強く推奨しています。ゲーム内のヒントスターは貴重なリソースです。後のチャプターでパズルの複雑さが跳ね上がった時のために温存しておけば、進行不能に陥るのを防ぐことができます。

コミュニティの攻略フォーラムで共有されている、効率的に捜査を進めるための実践的な鉄則をご紹介します。

- **収納部は必ず2回調べる:** 引き出しや箱には、手前のアイテムの奥や下に別の証拠が隠されていることが多々あります。開けた収納スペースは必ずもう一度タップし、取り残しがないか確認してください。
- **義肢や衣服を細部まで調べる:** 身体の調査では、複数の異なる部位（手、ポケット、手足、首元など）を個別に調べる必要があります。1箇所でも見落とすと、金庫やドアのロックが解除できなくなります。
- **シンボルの対応をメモする:** 記号と数字を一致させる暗号を解く際は、紙にアイコンを描いて整理しましょう。薄暗い現場では、波線のタトゥーとドクロのエンブレムが混同しやすくなります。
- **インベントリのアイテムを回転・観察する:** 一部の手がかりは、インベントリ画面で詳しく回転・拡大して確認しなければ、部屋の環境内で使用可能なパズルキーとして認識されない場合があります。

『On Thin Ice AE Mysteries』のゲーム進行のペースを掴むことで、スターを節約し、推理スピードを上げ、時間との過酷な戦いを繰り広げるケイト・グレイのサスペンスストーリーを余すところなく楽しむことができます。

## 『On Thin Ice AE Mysteries』に関するよくある質問（FAQ）

### 『On Thin Ice AE Mysteries』のクリアにかかる時間はどれくらいですか？
氷の階段のような空間パズルを解くスピードやヒントの使用頻度にもよりますが、ほとんどのプレイヤーは全体を約3〜5時間でクリアしています。初見プレイの場合、チャプター1はおよそ30〜45分程度かかります。

### パズルをスキップすることはできますか？
はい。どうしても解けないパズルや難易度が高すぎるミニゲームは、ゲーム内スターを消費することでスキップ可能です。ただし、スターは課金しない限り入手数が限られているため、完全にスキップするよりも攻略ガイドの解答手順を参照することをおすすめします。

### 小屋で見つけたスマホがハックソーの顔でロック解除できない場合はどうすればいいですか？
まず、ワイヤレス充電ドックと車のケーブルを使用してスマホを完全に充電したか確認してください。また、生体認証を行う前に、ケイトとマーフィーの会話シーケンスが最後まで完了している必要があります。

### 床の金庫に「9416」を入力しても開かないのはなぜですか？
濡れたカーテンの布を使って、テンキーから乾いた血痕をあらかじめ拭き取っておく必要があります。メカニズムに血が付着したままだとテンキーを正しく押すことができず、番号の入力が受け付けられません。
