『On Thin Ice』のエレベーターパズルは、周囲のわずかな手がかりを1つでも見落とすと、捜査が完全にストップしてしまいがちな難所です。『Adventure Escape Mysteries: On Thin Ice』で、ケイト・グレイ刑事と相棒のペニーは、猛吹雪で麻痺した大都市を舞台に緊迫の陰謀劇に立ち向かいます。裏切り者の交渉人サラ・“スティコウスキー”（スティックス）を追って厳重に警備された企業ビルへ潜入するものの、警備ロボットが立ちはだかりエレベーターが封鎖されてしまいます。

Haiku Games作品のベテラン探偵でもシリーズ初プレイの初心者でも、このエレベーターパズルを突破するには鋭い観察力、的確なアイテムの組み合わせ、そして論理的な回路の配線が不可欠です。本攻略ガイドでは、貴重なスター（ヒント）を消費することなくエレベーターを起動し、スティックスのオフィスへ到達できるよう、ロビーシークエンスの全工程をステップ・バイ・ステップで徹底解説します。

## チャプター2 ロビーの概要：警備システム、ロボットの防衛、入手アイテム

猛吹雪が吹き荒れる中、企業本部に到着するところから緊迫のチャプター2が幕を開けます。目的はシンプルで、タワーのエレベーターを使ってサラ・スティコウスキーのペントハウスオフィスへ向かうこと。しかし、ロビーの自動受付ロボット「ロビー・ボット（Lobby Bot）」によって、移動システム全体がロックダウンされています。

警備エリアを突破するには、周囲の設備を調べ、メンテナンスパネルを操作し、装飾品の後ろなどに隠されたツールを見つけ出す必要があります。このシーンにあるすべてのオブジェクトには明確な役割があり、連鎖的な謎解きが組み上げられています。

中央の回路マトリックスに手をつける前に、ロビー内をくまなく調べて必要なアイテムを回収しなければなりません。観葉植物の鉢を動かし、照明設備を取り外し、利用可能な配線を回収することが、メンテナンス用スペースを開くための重要な前提条件となります。

| ロビーのアイテム | 入手場所／入手方法 | ゲーム内での用途 |
| :--- | :--- | :--- |
| **彫刻の破片** | 観葉植物の裏にある隠しスイッチを作動させた後、床に落ちる | 隠されたメンテナンス収納扉をこじ開けるためのくさびとして使用 |
| **銅線** | ロビー・ボットの会話の手がかりで開く壁の金庫内 | ロビー・ボットに巻きつけて電流を流し、計画的なショートを起こす |
| **ツールボックスのドライバー**| 隠されたメンテナンス用の壁の空洞内 | 壁のコントロールパネルから主電源スイッチプレートを取り外す |
| **脚立** | 隠されたメンテナンス収納内に保管されている | ケイトが高い天井の照明器具に届き、コンデンサを回収できるようにする |
| **フラッシュコンデンサ** | 頭上のシャンデリア／照明器具（脚立が必要） | 銅線を通じて高電圧パルスを送り、ロボットを停止させる |
| **コンピュータチップ** | 開いたロビー・ボットの胸部シャーシから直接取り出す | 回路の再プログラミングパズルを解くために必要なキースロットタイル |

## エレベーターパズル＆ロビー・ボット攻略手順

エレベーターを起動するには、まずロボットへの尋問から始まります。ロビー・ボットに話しかけ、選択できる4つの対話選択肢をすべて確認してください。ロボットは素っ気ない態度に見えますが、その音声合成チップは企業理念の言葉に偽装された重要なセキュリティコードを漏らしています。

ロボットの話し方の中で大文字や強調されている単語、**FIRST（最初）**、**CENTRAL（中央）**、**LAST（最後）**に注目しましょう。この3つのキーワードは、ロビー入口付近にある壁面金庫のダイヤルで合わせるべき3つの幾何学記号に直接対応しています。

### ロビーの金庫の暗証番号を解読する

金庫のダイヤルには、抽象的な電子記号が並んでいます。ロボットのセリフから得た手がかりを各位置に合わせることでロックが解除されます。

| 手がかり | 強調されたキーワード | 記号の特徴 | ダイヤルの位置 |
| :--- | :--- | :--- | :--- |
| 最初の問い | **FIRST** | 途切れた円のような2重の曲線アーチ | 左側 |
| 中間の問い | **CENTRAL** | 水平バーが交差する同心菱形 | 中央 |
| 最後の問い | **LAST** | 垂直に3本並んだ下降線 | 右側 |

この順番で記号を入力すると金庫が開き、中から銅線のスプールを入手できます。

### ロボットを意図的にショートさせる

銅線を入手したら、ロビー・ボットの周囲に巻きつけます。セキュリティロックアウトプロトコルを過負荷（オーバーロード）状態にするには、強力な電気パルスが必要です。大きな観葉植物をスライドさせて隠されたラッチを露出させ、彫刻の破片を使ってメンテナンスロッカーをこじ開けます。中から脚立とドライバーを回収しましょう。

吊り下げ照明の下に脚立を置き、安全にフラッシュコンデンサを取り外します。次に、壁のコントロールパネルにドライバーを使って主電源スイッチを取り外します。コンデンサとスイッチをロボットに巻いた銅線に直結します。スイッチをオンにすると、ロビー・ボットの内部レギュレーターが過負荷を起こし、胸部シャーシが開いて壊れたロジックプロセッサ（コンピュータチップ）が飛び出します。

```
[壁のスイッチ] ---> [フラッシュコンデンサ] ---> [銅線] ---> [ロビー・ボットのコア]
                                                                     |
                                                                (過負荷)
                                                                     v
                                                         [コンピュータチップが落下]
```

### 回路基板の再プログラミングパズルを解く

コンピュータチップを回収したら、ロボットのメインフレームに差し込んで再プログラミングのミニゲームを開始します。このグリッドこそが、『On Thin Ice』エレベーターパズルの最重要パートです。

目的は、回路基板グリッド上にすべてのチップタイルを配置し、すべての端が隣接するタイルとぴったり接続するようにすることです。各チップには、東西南北の端に向かって回路の配線ライン、端子ピン、または色分けされたパスが描かれています。

```
       [ 北 ]
  [西] [チップ] [東]
       [ 南 ]
  ルール: 隣り合うチップ同士で、接する辺の
          配線数・形状が完全に一致している必要がある。
```

効率よく基板を完成させるための攻略ポイントは以下の通りです。

*   **まずは四隅（コーナー）のピースを特定する:** 直角をなす2辺が平らで配線がないチップを探します。これらは必ず外周の四隅に配置されます。
*   **バスライン（幹線配線）を追う:** 水平に伸びる二重線の配線を追跡します。これらは通常、回路基板の中央列を横断するラインになります。
*   **端子ピンの数を確認する:** 内側の辺に3本の銅リード線がある場合、隣り合うタイルの向かい合う辺も3本のリード線でなければなりません。
*   **無理に合わせない:** 右隣のタイルと一致していても上のタイルと合わない場合は、すぐに回転させるか別のタイルと交換しましょう。

正しく配置を完了するとロビー・ボットのルーティングプロトコルが再起動し、直通エレベーターのドアが開いて、ケイトとペニーは役員フロアへの進入許可を獲得できます。

| 回路タイルのタイプ | 端の特徴・識別方法 | 最適な配置場所 |
| :--- | :--- | :--- |
| **コーナーユニット・アルファ** | 上と左が平坦、下部に2重バス配線 | 左上隅（1行目・1列目） |
| **T字ジャンクション・ベータ** | 北/南に3本ピン、東に高速配線1本 | 中央列（2行目・2列目） |
| **バスブリッジ・ガンマ** | 西から東へ伸びる水平2重配線 | 中段コネクタ（2行目・3列目） |
| **コーナーユニット・デルタ** | 下と右が平坦、上部にピン1本 | 右下隅（3行目・4列目） |
| **アース端子（グラウンド）** | 南にマルチリードのアースパターン、北に配線1本 | 最下段（3行目・2列目） |

## ペントハウスへの潜入：スティックスのオフィスと本棚の謎

エレベーターを出ると、サラ・“スティコウスキー”（スティックス）の拠点に直結しています。このフロアに到達したことで、エレベーターパズルが最初の試練にすぎなかったことがわかります。スティックスがランサムウェア集団「ハックソー（Hacksaw）」との繋がりを示す重要証拠を破棄する前に、彼女を追い詰めなければなりません。

### 対話の選択肢と発煙筒の無力化

スティックスに対峙する際、攻撃的な選択肢を選ぶと警戒されてしまいます。一時的に油断させて警戒を解くために、以下の順序で選択肢を選びましょう。

1. *「私たちには報酬が出ないの」*
2. *「ハックソーの証拠なら持っている」*

回収したハードディスクを提示して彼女を会議テーブルへ引き寄せます。ケイトの内心の反応を選択する場面では、冷静さを保つために*(夕食のことを考える)*を選びます。ペニーが身柄確保に動きますが、スティックスは軍用スモークグレネードを起爆し、秘密の脱出口から逃走してしまいます。

視界を奪う煙を払うため、デスクチェアをどかしてコンセントを使えるようにし、床に落ちているポータブル送風機を拾ってコンセントに差し込み、部屋を換気します。

```
[煙が充満した部屋] 
         │
         ├── デスクチェアを動かす
         ├── 送風機を拾う
         └── コンセントに接続 ──> [部屋の煙を排出し、手がかりを発見]
```

### 本棚のトロフィー配置パズルを解く

煙が晴れたら、部屋をくまなく探索します。カーテンのロープを回収し、ダクトテープで壊れたデスクランプを修理し、天井のシャンデリアに引っかかっている金庫の鍵をロープで投げ縄のようにして引き寄せます。壁の金庫を開けると、以前のオフィスのレイアウトが写ったポラロイド写真の束が手に入ります。

金属クランプを使って棚の下に落ちた記念プレートを拾い上げれば、スティックスの大きな飾り棚を正しく並べるためのアイテムがすべて揃います。

| 展示アイテム | 外見の特徴 | 正しい棚の位置（写真基準） |
| :--- | :--- | :--- |
| **マトリョーシカ** | サイドボード付近で見つかる木製の人形 | 上段・一番左 |
| **記念プレート** | クランプで拾い上げた真鍮製の盾 | 中段・中央 |
| **モダニズムのブックエンド** | 重厚な黒曜石風の幾何学ブロック | 下段・中央左寄り |
| **陶器の置物** | サイドボードに保管されていた繊細な白い像 | 中段・一番右 |
| **額装された学位記** | デスク脇に立てかけられた黒い木製フレーム | 上段・中央右寄り |

ポラロイド写真通りにこれらのアイテムを正確に並べると隠し収納が開き、恐喝組織を壊滅させるための暗号化ファイルを入手できます。これでロビーに戻り、チャプターをクリアすることができます。

## よくある失敗とトラブルシューティング

チャプター2を進める際、ロビーでツールを集めてからエレベーターを通電させるまでの間に詰まってしまうプレイヤーが多く見られます。コミュニティの報告でよく挙げられるつまずきポイントは以下の通りです。

*   **壁のスイッチが外れない:** スイッチは彫刻の破片では外せません。観葉植物の後ろにある隠しメンテナンス収納からドライバーを見つける必要があります。
*   **コンデンサが放電しない:** コンデンサをロボットに直接接続しても作動しません。まず銅線と壁のスイッチを組み合わせて作った回路ループに接続する必要があります。
*   **回路基板の回転ミス:** 一部のモバイル版アップデートでは、チップ配置時に自動回転しない場合があります。チップが合っているはずなのにセットできない場合は、インベントリ内でタイルをタップ（またはダブルクリック）して向きを変えてからスロットに配置してください。
*   **床の彫刻の破片の見落とし:** タイルの床に落ちた割れた彫刻の破片をタップし忘れるケースが多発しています。この破片がないとメンテナンスパネルを開けられません。

Haiku Gamesの手がける謎解きアドベンチャー作品をもっと楽しみたい方は、公式のゲーム概要やアップデート、コミュニティ情報が掲載されている[Haiku Games Official Website](https://www.haikugames.com)をチェックしてみてください。

各仕掛けがどのように連動しているかを把握していれば、単純なアイテムの見落としで貴重なヒント用スターを無駄遣いせずに済みます。

## よくある質問（FAQ）

### ライトのスイッチを取り外すための工具はどこにありますか？
ドライバーは、ロビーの壁にある隠しメンテナンス扉の奥の赤いツールボックスに入っています。アクセスするには、部屋の左側にある大きな観葉植物を動かして壁のラッチを露出させます。ラッチを操作して天井から吊り下げられた彫刻を落とし、床から尖った彫刻の破片を拾って、その破片でメンテナンス扉をこじ開けてください。

### 壁の金庫を開けるためのロビー・ボットの手がかりはどう解読しますか？
ロビー・ボットに話しかけ、選べる選択肢をすべて聞いてください。大文字で強調された単語「FIRST」「CENTRAL」「LAST」に注目します。それぞれの文章は、壁の金庫にある幾何学記号と結びついた企業理念を示しています。1つ目の記号を左のダイヤル、中央の記号を真ん中のダイヤル、最後の記号を右のダイヤルに合わせることで金庫が開き、銅線を取り出せます。

### エレベーターパズルの回路基板がうまく固定・完了しない場合はどうすればいいですか？
すべてのチップを配置しても自動的に完了しない場合は、接続部分の向きが逆になっている箇所があります。四隅以外のチップを一度グリッドから外し、境界線のピン数を確認してください。すべての配線ラインは、隣接するチップと同じ太さ・間隔のラインと向かい合う必要があります。特に向きを間違えやすい中央のT字ジャンクションタイルを重点的にチェックしてください。

### 間違った操作をするとエレベーターパズルは最初からリセットされますか？
いいえ、間違った位置にタイルを置いてもパズルがリセットされたりペナルティが発生したりすることはありません。スターを消費したりチャプター2をやり直したりすることなく、何度でもグリッドからチップを外して配置し直すことができます。
