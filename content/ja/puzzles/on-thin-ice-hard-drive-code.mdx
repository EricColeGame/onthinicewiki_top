## On Thin Iceのハードドライブコードを解読：解答速報と内訳

警察署のブリーフィングルームにある暗号化されたハードドライブのロックを解除するには、次の6桁のコードを入力してください：

> **ハードドライブのコード：21 10 12**

**211012**と入力するとストレージケースが開き、ケイトとマーフィーは重要な証拠を技術部門へ持ち出せるようになります。

このロックには、マーフィーの捜査ボードに貼られた特定の3人の容疑者に対応する、色分けされた2桁ずつのスロットが使用されています：
* **青の数字（最初の2桁）：** 21
* **赤の数字（真ん中の2桁）：** 10
* **緑の数字（最後の2桁）：** 12

```
[  2  1  ]   [  1  0  ]   [  1  2  ]
     青           赤           緑
(Blackjack)   (Dimebag)     (Nooner)
```

数字を入力してもドライブが開かない場合は、色の順番を正しく読んでいるか確認してください。このパズルは、ドライブ側の数値枠の色と、掲示板にある容疑者の顔写真を囲むマーカーの色を一致させることがポイントです。

| 手順 | 必要なアクション | 証拠の手がかり | 導き出される数字 |
| :--- | :--- | :--- | :--- |

| **2. ボードの修理** | 警察バッジシールの下の断線したワイヤーをテープで補修 | ボードのLEDライトが復旧 | 特定の3人の容疑者が強調表示される |

## ステップ別詳細攻略：容疑者ボードの発見と修理

**On Thin Iceのハードドライブコード**を割り出す前に、ケイトはマーフィーの容疑者ディスプレイボードへの電力供給を復旧させる必要があります。最初にボードを調べた時点では回路がショートしており、バックライト枠が点灯しません。

### 1. 配線のショートを修理する
1. コルクボードの右下をタップして、配線の不具合を確認します。
2. 露出した配線を隠している公式警察バッジのステッカーを剥がします。
3. インベントリ（または近くのデスク備品）から絶縁テープを取り出し、ほつれたワイヤーを補修します。
4. テープを巻くと電流が安定し、カラーバックライトで照らされた3人の容疑者のプロフィールが浮かび上がります。

### 2. 犯罪者の通称（エイリアス）を数字に変換する
強調表示された各プロフィールにはストリートの通り名（ニックネーム）が記載されており、それがそのまま一般的な数値に対応しています。多くのプレイヤーが日付やバッジ番号を探して混乱しがちですが、単純な言葉遊び（スラング）が鍵となります：

* **Blackjack（青い枠）：** トランプゲームの「ブラックジャック」では、目指す手札の合計値は21です。これにより、青の数値**21**が得られます。
* **Dimebag（赤い枠）：** ストリートスラングで「Dime（10セント硬貨）」は数字の10（または10ドル分のパケ）を指します。これにより、赤の数値**10**が得られます。
* **Nooner（緑の枠）：** 「Nooner」は真昼・正午（午後12:00 / 12時）を指す俗語です。これにより、緑の数値**12**が得られます。

| 容疑者の通称 | ボードの枠色 | スラング／文脈の意味 | 数値への変換 | ハードドライブの入力位置 |
| :--- | :--- | :--- | :--- | :--- |
| **Blackjack** | 青 | ブラックジャックの勝利手札（21点） | **21** | スロット 1 & 2（青） |
| **Dimebag** | 赤 | 10ドルの単位 / 10（ダイム） | **10** | スロット 3 & 4（赤） |
| **Nooner** | 緑 | 正午 / 12時（ヌーン） | **12** | スロット 5 & 6（緑） |

ドライブの色の並び順に合わせて数字を並べると、**21-10-12**となります。これを入力するとドライブがカチリと解錠され、ケイトはデータ消去セキュリティを発動させることなく内部ハードウェアを取り出せます。

## ダンのPCの組み立てとモニターPINコードの解読

ケイトのワークステーションは既に悪質なランサムウェアに感染しているため、ハードドライブを自分の端末に直接接続することはできません。安全に接続するため、階下にあるダンのオフィスへ向かう必要があります。

オフィスに入ると、ダンは散らかった部屋とコンピュータ部品に囲まれ、デスクで居眠りをしています。彼の端末にアクセスするには、彼を起こして水冷式デスクトップPCを組み立て直さなければなりません。

### 1. 部屋の片付けとパーツの収集
* ダンのデスクや床に散乱しているゴミ、コーヒーカップ、書類を片付けます。
* ダンの下敷きになっている毛布を引っ張り出し、追加のハードウェアを見つけます。
* **マジックハンド（grabber tool）**、**2つの冷却ファンベイ**、**リモコン**、**キャビネットの取っ手**を回収します。
* 鍵のかかったサイドボードの引き出しにキャビネットの取っ手を取り付け、**フレキシブルプラスチックチューブ**を入手します。
* 下の備品引き出しを開けて、**水冷クーラントボトル**を入手します。
* マジックハンドを使ってロッカーの上部に手を伸ばし、エナジードリンク**「Zap Cola」**の缶を回収します。

Zap Colaをダンに渡します。彼が目を覚ましたら、椅子の下からハイエンドな**グラフィックボード**と**マイクロファイバークロス**を回収します。

### 2. ハードウェアの接続
開いているPCケースを調べ、以下の論理的な順序でコンポーネントを取り付けます：
1. **2つのファンベイ**をPCケースの前面ブラケットと背面ブラケットに取り付けます。
2. **グラフィックボード**をプライマリPCIeスロットに挿入します。
3. 冷却ブロックとラジエーターリザーバーの間に**プラスチックチューブ**を配管します。
4. 水冷ループに**クーラント液**を注ぎます。
5. 最後に、**On Thin Iceのハードドライブコード**を使って取り出した暗号化解除済みドライブをドッキングします。

### 3. ダンの4桁モニターPINの解読
ダンはワークステーションのPINコードを忘れてしまっています。これを見つけるには、マイクロファイバークロスを使ってデスク上の汚れたデジタルフォトフレームを拭きます。フォトフレームは2枚の写真の間で画面が乱れているため、**リモコン**を使って再生サイクルを修復します。

モニターのロック画面を確認します。以下の4つのアイコンが順番に表示されています：
`[ 赤のストップウォッチ ] → [ 青の雪の結晶 ] → [ オレンジの魚 ] → [ 緑の歯車 ]`

デジタルフォトフレームの写真を順送りし、各アイコンを写真内の数字と一致させます：

| アイコン | 関連する写真のテーマ | 写真内の視覚的手がかり | 対応する数字 |
| :--- | :--- | :--- | :--- |
| **赤のストップウォッチ** | 脱出ゲームのお出かけ | 部屋のタイマー表示板 | **5** |
| **青の雪の結晶** | スキー／スノーボード旅行 | ゼッケンに印刷された番号 | **3** |
| **オレンジの魚** | 寿司屋でのディナー | 皿の枚数／テーブル番号カード | **9** |
| **緑の歯車** | ロボット工学大会 | ロボットのエントリー番号デカール | **7** |

**5397**と入力するとダンのコンピュータのロックが解除され、内部ファイル検査ユーティリティが立ち上がります。

## ハードドライブのデータ整理パズルを攻略する

OSに入るとダンは再び眠りに落ち、ケイトは断片化したクラスタの整理を一人で進めることになります。破損したブロックと有効な監視ログを分離するため、端末画面上でデータレーンの並べ替えパズルを解く必要があります。

### データソーターのルール
このパズルでは、3つの行に色分けされたデータブロックが配置されています。目的は、すべての色が指定されたチャンネルに分かれるようにブロックを移動させることです：
* **上段：** 黄色のデータブロック
* **中段：** 白のデータブロック
* **下段：** 緑のデータブロック

### 素早く仕分けるための攻略のコツ
コミュニティのプレイヤー経験則によると、タイルのループにハマって手詰まりになるのを防ぐ最も簡単な方法は、左から右へ解いていくことです：
1. **まず角を片付ける：** 上段レーンの横移動を妨げないよう、緑のタイルはすぐに下段のトラックへ移動させます。
2. **中央をバッファとして活用する：** 中段（白）レーンは最も分岐の融通が利きます。緑のブロックを下へ送る間、位置が違う黄色タイルを一時的にここに退避させておきましょう。
3. **外側の列を固定する：** 1列目と2列目がそれぞれの行の色と一致したら、それ以上動かさないようにします。残りのタイルは右側のトラック内だけで揃えていきます。

データブロックを整理し終えると、ケイトは衝撃的な真実を知ることになります。警察署を人質に取ったランサムウェアをアップロードした内部工作員は、他ならぬダンだったのです。

## 警官たちの注意をそらし、証拠品ロッカーを開ける

ケイトがダンを単独で尋問するためには、処理室からジェイコブ刑事、マーフィー、ケイコを退室させなければなりません。

### 1. 部屋から同僚を退出させる
* 尋問室のカートから**手指消毒剤**のボトルを取ります。
* 壁にある額縁に入った警察規則の掲示を落とし、**硬いワイヤー**を入手します。
* ワイヤーを使って仕切りの隙間からジェイコブのキーリングを釣り上げます。
* 奥の壁にある備品ロッカーの鍵を開けます。

### 2. ロッカーコード「40242」を解読する
2つ目のロッカーには5桁の暗証番号が必要です。汚れた暗証番号パネルに手指消毒剤を使うと、5つのカテゴリラベルが現れます：**HANDS（手）**、**NO ITEMS（持ち込み禁止）**、**SHIRTS（シャツ）**、**SHOES（靴）**、**MOUTHS（口）**。

壁の規則には、囚人1名につき面会者は厳格に**1名のみ**に制限されると明記されています。したがって、計算はちょうど**2人分**（被拘禁者と面会者1名）でカウントする必要があります：

| カテゴリ／単語 | カウントの論理（2人分：囚人1名＋面会者1名） | 算出される数字 |
| :--- | :--- | :--- |
| **HANDS（手）** | 2人 × 両手（2本） | **4** |
| **NO ITEMS（所持品なし）** | 規則により外部からの物品持ち込みは厳禁 | **0** |
| **SHIRTS（シャツ）** | 2人 × シャツ各1枚 | **2** |
| **SHOES（靴）** | 2人 × 靴各2足（左右一対） | **4** |
| **MOUTHS（口）** | 2人 × 口各1つ | **2** |

**40242**と入力すると、安全保管ロッカーが開きます。

```
ロッカー入力：[ 4 ] - [ 0 ] - [ 2 ] - [ 4 ] - [ 2 ]
```

### 3. 目撃者を散会させる
ロッカーの中から、押収されたダンの私物を回収します。各人にタスクを割り振って部屋から退出させます：
1. **ダンの私物**をケイコに渡し、物品目録の記録作業に戻らせます。
2. **現場規制線テープ**をマーフィーに渡し、階下へ向かわせます。
3. 処理済みの**逮捕書類**を取ってジェイコブに渡し、書類整理に行かせます。
4. ワイヤーのフックを使って**ブリキのコップ**とダンの**老眼鏡**を取ります。
5. ラジエーターから滴る水をコップに溜め、ダンに浴びせて起こし、眼鏡を渡して尋問を開始します。

## よくある質問（FAQ）

### チャプター3のOn Thin Iceのハードドライブコードは何ですか？
正確な**On Thin Iceのハードドライブコード**は**211012**です。これは容疑者のニックネームであるBlackjack（21）、Dimebag（10）、Nooner（12）から導き出され、ドライブケースの青・赤・緑のカラー枠の順に並べたものです。

### 『On Thin Ice』で容疑者ボードのライトが点かないのはなぜですか？
容疑者ボードのフレーム下で配線がショートしています。警察バッジのステッカーをタップして剥がし、露出した断線箇所に絶縁テープを貼ることで、カラーLED枠の電源を復旧させる必要があります。

### ダンのコンピュータモニターのPINコードは何ですか？
モニターのPINコードは**5397**です。これはロック画面に表示されている4つのアイコン（ストップウォッチ、雪の結晶、魚、歯車）に対応しており、ダンの修復されたデジタルフォトフレームの写真内の数字と一致しています。

### 警察署の5桁のロッカー暗証番号は何ですか？
暗証番号は**40242**です。これは2人分（囚人1名＋面会者1名）の身体的特徴・規則を計算したものです：手4本、持ち込み禁止アイテム0個、シャツ2枚、靴4足、口2つとなります。
