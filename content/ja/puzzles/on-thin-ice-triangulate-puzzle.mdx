## 「薄氷」三角測量パズルの概要

『Adventure Escape Mysteries: 薄氷（On Thin Ice）』で、ケイト・グレイ刑事とマーフィーは、危険なサイバー攻撃、警察ネットワークの侵害、そして人里離れた山小屋で発見された情報提供者の変死体が絡む事件の捜査に挑みます。チャプター1のクライマックスは、ハックソーの隠れ家にあるキャビネットの扉の奥に隠された電子セキュリティボックスの解除です。

**三角測量パズル**に挑戦する前に、まずは回路ボードを完全に機能する状態へ復旧させる必要があります。ハックソーは重要な三角形の回路部品を取り外し、敷地内の施錠された容器に隠していました。不足している3組の三角ピースをすべて見つけるとボードが起動し、インタラクティブな電気回路の迷路が出現します。

このパズルの目的は、光るエネルギーパルスを開始ノードからボードの右端にある黄色のレセプター（受容）三角形まで導くことです。1歩進むごとに足元のタイルが回転するため、無計画に動かすと回路の接続が途切れ、最初からやり直す羽目になります。

## 事前チェックリスト：不足している三角ピースの入手先

チャプター1の各所に散らばる3組の三角ピースをすべて集めるまで、パズルを操作することはできません。それらを見つける前にキャビネットを調べても、回路ボードは暗いまま不完全な状態です。

```
[山小屋内部の金庫] ──> 三角ピース第1セット
[全焼した車の工具箱] ──> 三角ピース第2セット
[前庭の郵便ポスト] ──> 三角ピース第3セット
         │
         ▼
[キャビネットの電気ボード] ──> 三角測量パズルが起動
```

### 1. 床下の金庫（三角ピース第1セット）

小屋の中でマットレスとラグをどかし、緩んだ床板を露出させます。部屋で見つかる金切りのこぎり（Hacksaw）を使って床板を切断し、血痕のついた施錠された金庫を取り出します。

外に出て水たまりで布のカーテンを濡らし、室内に戻って金庫の文字盤を拭き取ります。ハックソーの遺体にあるタトゥーの記号を数えます：
- 矢印：9
- ドクロ：4
- ハート：1
- 波：6

金庫のキーパッドに暗証番号「**9416**」を入力すると、最初の三角ピース一式、決定的な手紙、そしてロックピッキングガンが手に入ります。

### 2. 全焼した車のロックボックス（三角ピース第2セット）

小屋の勝手口にロックピッキングガンを使って屋外の広場へ出ると、炎上する車両があります。グリルの防水シートの下にある消火器を取り、火を消し止めた後、現場で入手したバールを使って車のドアをこじ開けます。

車内から外れた充電コードを回収し、山小屋に戻ってハックソーの車椅子に給電します。レンチで機構を締めると、小さな鍵が落ちてきます。この鍵を持って全焼した車に戻り、潤滑油（クリーニングオイル）で金属製ロックボックスの錆を落として開錠すると、2組目の三角ピースとドライバーを入手できます。

### 3. 前庭の郵便ポスト（三角ピース第3セット）

ドライバーを手に入れたら、山小屋内にいるハックソーの義足の収納スペースを開け、バッテリーの切れたスマートフォンを取り出します。先ほど回収した車両用コードを使って、スマートフォンをワイヤレス充電器に置きます。

電源が入ったら、ハックソーの顔に端末をかざして顔認証セキュリティを解除します。メッセージを確認すると、玄関前の郵便ポストに配達物が届いていることが判明します。小屋の入り口の外に出て、スマートフォンでポストの認証を行い、最後の三角ピースと印刷された技術チャートを回収します。

## パズルの仕組みとルール解説

3組すべてのピースをキャビネットの機構にはめ込むと、ボードに通電します。この**三角測量パズル**は、ケイト・グレイの他のアドベンチャーシリーズに見られる従来のスライドパズルや配線パズルとは大きく異なります。

[Haiku Games公式サイト](https://www.haikugames.com)のパズル解説にもあるように、同スタジオは決定論的なルート選択と空間変換を軸にロジックチャレンジを設計しています。その設計哲学はここでも明確に表れています。

* **初期位置：** 電気軽点は、左端の点灯している三角形ノードからスタートします。
* **移動可能な候補：** 現在地と通電可能な接点を共有している隣接した三角形がハイライトされます。
* **タイルの回転／動的変化：** 電流が新しい三角形へ進入するたびに、その三角形が即座に**時計回りに90度回転**（または辺の位置が1ステップ進行）します。
* **クリア目標：** 幾何学グリッドを横断して電流を誘導し、右端にある固定された黄色のターミナルに接続することです。

三角形に着弾するとその内部の導線が回転して向きが変わるため、間違えたからといって簡単に後戻りはできません。誤ったステップを踏むと先の導線が遮断され、袋小路のタイルに取り残されてしまいます。

| パズル要素 | 機能 | 動作ルール |
| :--- | :--- | :--- |
| **現在のタイル** | 進行中の電流を保持 | 接続可能な隣接タイルへ方向パルスを放射 |
| **ハイライトされた隣接タイル** | 次の移動候補 | 接続導線の位置が合致している場合のみ選択可能 |
| **動的な回転** | 進入時に時計回りに回転 | 以降の通過に備えてボード状態を恒久的に変化させる |
| **黄色の目標タイル** | 右端のゴールノード | 電流が到達するとパズルクリアとなり金庫が開く |

## 三角測量パズルの解き方：ステップ・バイ・ステップ手順

**三角測量パズル**を解くには、タイルの回転を考慮しながらルートを選択する必要があります。光の点がタイルを回転させた結果、後続のノードとの接続が切れると、進路を失ってしまいます。

プレイヤーの実証結果およびコミュニティの検証報告に基づき、初期状態から以下の手順通りに進めれば、行き止まりになることなく確実にターミナルまで到達できます。

```
[開始ノード（左）] ──> 手順1（右上） ──> 手順2（右）
                                               │
[目標ノード（黄）] <── 手順5（右端） <── 手順4（右下） <── 手順3（下）
```

### 各ステップの詳細な進行方向

1. **手順1（最初の一歩）：** 左の開始ノードから、ハイライトされている右上の三角形を選択します。電流が入るとタイルが時計回りに回転し、上部ルートの導線が接続されます。
2. **手順2（右へ直進）：** すぐ右隣の前方を向いた三角形をタップします。電流が前進し、2回目の回転が発生します。
3. **手順3（下方への移行）：** 電流を中央の三角形へと下方向へ進めます。この回転により、下部導線がゴールエリアと一直線に繋がります。
4. **手順4（下部ルート）：** ハイライトされている右下の三角形へ進みます。回転によって出力端子が最終レセプターに直接向き合います。
5. **手順5（最後の接続）：** 右端の黄色ノードへと続く光るパスをタップします。

電流が黄色のターミナルに接続されると回路がロックされ、チャイムが鳴ってキャビネット内の隠しコンパートメントが開き、極めて重要な**写真**が手に入ります。

| 手順番号 | 移動方向 | 主要エリア | 回転後のタイルの状態 |
| :---: | :--- | :--- | :--- |
| **1** | 右上 | 北西クラスター | 東（右）方向へ通電 |
| **2** | 真右 | 中央北側ルート | 下方向へ向きを変更 |
| **3** | 下 | 中央クロスウェイ | 南東への接続路を開放 |
| **4** | 右下 | 南東エリア | 目標ターミナルと向きが一致 |
| **5** | 右（目標へ） | 東端ターミナル | 回路が完成し収納トレイが開く |

このガイドを見る前にタイルを適当にタップしてしまった場合、配置がずれている可能性が高いです。その場合は、一度キャビネット画面から出て戻るだけで初期配置にリセットされます。その後、上記の5ステップを順に実行してください。

## パズルクリア後の手順：ハックソーの隠し金庫を開ける

回路ボードの謎を解くだけでは終わりではありません。**三角測量パズル**を完了することで、ハックソーのメインデータ保管庫を暴くために必要な3つ目（最後）の重要アイテムを入手できます。

大きな掲示板が掛かっている山小屋の奥の壁を調べます。ここで以下の3つの証拠を組み合わせる必要があります：
1. **手紙：** 床下の金庫から回収。
2. **チャート：** 外の郵便ポストから回収。
3. **写真：** 三角測量パズルクリア時にドロップ。

```
[手紙]   ──┐
[チャート] ──┼──> [山小屋の壁のピンボード] ──> 隠し金庫が開く ──> [暗号化ハードドライブ]
[写真]   ──┘
```

3つの書類をすべて壁のピン留め枠に配置します。手がかりを正しい位置に合わせると、パネルの裏側にあるロックが解除され、ハックソーの頑丈な壁内金庫が現れます。中には、ケイトとマーフィーの容疑を晴らすために必要なランサムウェア犯の正体と監視カメラ映像が保存された暗号化外付けハードドライブが入っています。

ハードドライブを入手するとチャプター1は終了し、吹雪が吹き荒れる街へと舞台を移すチャプター2へ突入します。

| 証拠品 | 入手場所 | 壁の金庫パズルでの役割 |
| :--- | :--- | :--- |
| **ハックソーの手紙** | 床下金庫（暗証番号：9416） | 状況解説メモと左側の位置合わせ基準を提供 |
| **技術チャート** | スマートポスト（玄関前） | 壁の見取り図に座標を重ね合わせる |
| **キャビネットの写真** | 三角測量パズルのクリア報酬 | 壁のラッチを外すための最終的な視覚キーを提供 |

## よくある失敗と攻略のポイント

この回路パズルの最短クリア手順は短いものの、進行に行き詰まってしまうプレイヤーが多く見られます。

### 1. 意図しない無限ループ
三角形は進入するたびに回転するため、「別のルートを試そう」と前のタイルに戻るとタイルの向きが変わってしまいます。コミュニティでも、隣接する2つの三角形を行き来するうちにタイルが外側を向いてしまい、脱出不能な2ノードループに陥ったという報告が多発しています。こうなった場合は、一度キャビネットから離れて画面を戻せばボードが初期状態にリセットされるため、時間を無駄にせずに済みます。

### 2. 必要な三角ピースが足りていない
キャビネットをタップしても何も起きない場合は、インベントリを再確認してください。接点が点灯してパズルが遊べるようになるには、3箇所すべて（金庫、全焼した車、郵便ポスト）から三角ピースを回収してボードにはめ込む必要があります。

### 3. 導線の向きの見間違い
電流は、導線の端と端がぴったり接触しているラインしか流れません。単に距離が近いからといって隣の三角形をタップせず、現在地の導線が次のタイルの入口ノードと正しく繋がっているかを必ず確認してから移動しましょう。

## よくある質問（FAQ）

### 三角測量パズルで無限ループにハマって動けなくなったらどうすればいいですか？
何度か誤った操作をして隣接するタイルを選択できなくなった場合は、キャビネットの拡大画面から完全に退出してください。山小屋の全体画面に戻ってから再度キャビネットをタップすると、**三角測量パズル**が初期状態にリセットされ、最初から正しい手順でやり直すことができます。

### チャプター1の3組目の三角ピースはどこにありますか？
3組目の三角ピースは、山小屋の外の玄関前にあるスマート郵便ポストに入っています。入手するには、車椅子を修理して小さな鍵を見つけ、全焼した車の錆びたボックスを開けてドライバーを入手し、ハックソーの義足からスマホを取り出して室内で充電、顔認証でロック解除したスマホを使ってポストを開ける必要があります。

### 三角測量パズルをクリアするとどんな報酬が手に入りますか？
パズルを解くとキャビネットのコンパートメントが開き、隠されていた写真が入手できます。この写真と、床下の金庫の手紙、郵便ポストのチャートを組み合わせることでハックソーのハードドライブが入った壁の金庫が開き、チャプター1クリアとなります。
