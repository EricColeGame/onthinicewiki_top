そのためにはエリア内に散らばる特定のアイテムを集める必要があり、中でも最も重要なのが警察のロッカー内に厳重に保管されているダンの私物です。この私物を手に入れるための最大の障壁となるのが、**On Thin Iceのロッカーの暗証番号**を解読することです。

ロッカーのキーパッドに数字を入力する前に、まずは留置室のロッカーがある場所への立ち入り権限を得て、キーパッドを調べられる状態にする必要があります。

## On Thin Iceのロッカー暗証番号の特定手順

留置室のドアを開けると、2つのロッカーが目に入ります。左側のロッカーは番号入力なしですぐに開き、「警察の証拠テープ」が手に入ります。しかし、右側のロッカーには最新の5桁の電子ロックがかかっています。

最初から電子ロックをタップしても、ケイトは「汚れすぎていて読めない」と言います。**On Thin Iceのロッカー暗証番号**を入力するには、まず持ち物からハンドサニタイザー（消毒液）を選び、キーパッド全体に使用する必要があります。これにより汚れが拭き取られ、5桁の入力パネルと、警察署の面会規則を確認するよう促すヒントが現れます。

```
キーパッドの表示順序:
[ HANDS ] - [ NO ITEMS ] - [ SHIRTS ] - [ SHOES ] - [ MOUTHS ]
（手）     - （持ち込み禁止）- （シャツ）  - （靴）     - （口）
```

### 面会規則の解読

数字の組み合わせを導き出すために、廊下の壁から落とした額入りの「面会規則（Visitor Rules）」のポスターに注目しましょう。多くのプレイヤーが、署内にいる警察官たち（ケイト、マーフィー、ジェイコブ、ケイコ、そしてダン）の人数を数えてしまうという間違いを犯します。コミュニティの報告によると、これがこの謎解きで詰まってしまう最も一般的な原因です。

このパズルの指示は、規則に明確に記載されている「仮の面会シナリオ」を分析することを求めています。

* **規則の記述**: 「囚人1名につき、一度に許可される面会者は1名のみとする。（Only one visitor is permitted per prisoner at any time.）」
* **想定される人数**: このシナリオにおける人数は、正確に**2名**（囚人1名 ＋ 面会者1名）です。

ここで、拭き掃除したキーパッドに表示されている大文字のキーワードと、案内板に記載された身体的特徴や厳格なルールを照らし合わせます。

| 項目 | シナリオの状況（合計2名） | 計算式 | 入力する数字 |
| :--- | :--- | :--- | :--- |
| **HANDS（手）** | 1人につき2本の手がある | 2名 × 2本の手 | **4** |
| **NO ITEMS（アイテム禁止）** | 規則により面会者の私物持ち込みは厳格に禁止されている | 持ち込み可能な私物はゼロ | **0** |
| **SHIRTS（シャツ）** | 服装規定により面会者と囚人はシャツを着用しなければならない | 2名 × 1枚のシャツ | **2** |
| **SHOES（靴）** | 靴の規定により1人につき1足（2つ）の靴が必要 | 2名 × 2つの靴 | **4** |
| **MOUTHS（口）** | 1人につき1つの口がある（規則では静粛な面会が定められている） | 2名 × 1つの口 | **2** |

**On Thin Iceのロッカー暗証番号**である **4 - 0 - 2 - 4 - 2** を入力すると、電子ロックが即座に解除されます。中には押収されたダンの私物が入っており、これが部屋から他の警察官たちを追い出すための重要なアイテムとなります。

## ロッカーを開けた後にやるべきこと

**On Thin Iceのロッカー暗証番号**を解いてダンの私物を手に入れたら、次の目標はケイトがダンと1対1で尋問できるように3人の同僚をフロアから立ち退かせることです。以下の手順通りにアイテムを渡して、部屋を無人にしましょう。

### 1. ケイコを移動させる
持ち物から**ダンの私物**を選択し、ケイコに渡します。彼女は証拠品の記録作業を始めるためにアイテムを引き取り、デスクを離れます。ケイコがいなくなったデスクを調べると、**逮捕書類**を入手できます。

### 2. マーフィーを現場へ向かわせる
マーフィー刑事のところへ向かいます。ダンのロッカーの隣にあった鍵のかかっていないロッカーから回収した**警察の証拠テープ**を彼に渡します。マーフィーは吹雪の中、現場周辺の規制線を張るためにすぐに立ち去ります。

### 3. ジェイコブを移動させる
ケイコとマーフィーがいなくなったら、ジェイコブ巡査に話しかけます。ケイコのデスクから回収した**逮捕書類**を渡します。ジェイコブは書類の手続き処理を行わなければならず、ケイトを留置エリアに1人残して持ち場を離れます。

### 4. ダンを起こして尋問する
部屋が空になったら、ケイトはぐったりしているダンを起こす必要があります。持ち物のワイヤーを使って、格子の隙間からダンの**メガネ**と**ブリキのマグカップ**を引っ掛けて回収します。
1. 天井の水漏れしているパイプの下にブリキのマグカップを置き、冷たい水をためます。
2. その水をダンに浴びせて目を覚まさせます。
3. はっきりと周りが見えるように、ダンにメガネを渡します。

```
ダン尋問の流れ:
冷水で起こす -> メガネを返す -> 犯罪組織の脅迫について聞く -> ベルトを受け取る
```

ダンは、サイバー犯罪組織に娘を誘拐され、ケイトのPCに身代金ウイルスを仕込むよう強要されたこと、そして優秀な刑事に逮捕されることを望んでいたと告白します。その後、ダンは自分のベルトを差し出します。持ち物の中でベルトを調べると、小さな真鍮の鍵が隠された秘密のポケットが見つかります。この鍵でオフィスのクローゼットを開けると、特殊な捜査用ノートPCが手に入り、チャプター4へと進みます。

## ロッカーコードを解く際によくある落とし穴

脱出ゲームの謎解きにはプレイヤーを惑わす要素がつきものであり、チャプター3にも誤解を招きやすい罠がいくつか用意されています。**On Thin Iceのロッカーコード**で多くの人がつまずく理由と、その回避策は以下の通りです。

| よくある間違い | 間違いの原因 | 正しいアプローチ |
| :--- | :--- | :--- |
| **部屋にいる人物を数えてしまう** | 「面会者」という言葉から、周囲に立っているケイト、ケイコ、マーフィー、ジェイコブのことだと思い込んでしまう。 | パズルは室内の人物ではなく、掲示されている面会規則に記載された架空のシナリオのみに基づいています。 |
| **アイテムを「0」ではなく「1」と入力する** | 「持ち込み禁止（No Items Allowed）」を1つの規則と捉え、数量を「1」と勘違いしてしまう。 | 「アイテムなし」は数学的に、持ち込みが許可されているアイテム数が「0」であることを意味します。 |
| **消毒液の使用を忘れる** | キーパッドが汚れてかすれている状態でタップし、ゲームのバグだと勘違いしてしまう。 | 最初に入力パネルを綺麗にするため、ハンドサニタイザーのボトルを選択して直接使用する必要があります。 |
| **靴の「ペア」と個数を混同する** | 靴を「1足（ペア）」として数えてしまい、単体の個数としてカウントしていない。 | このパズルの体の一部や衣服はすべて個数単位で数えます（2名 ＝ 靴4足分／4個）。 |

## 『Adventure Escape Mysteries』上級推理テクニック

『On Thin Ice』のパズル構成は、Haiku Gamesのクラシックな設計思想を忠実に反映しています。それは「環境内の手がかりは、決して完全に孤立して存在することはない」という点です。本作や今後のチャプターで行き詰まったときは、以下のポイントを意識してみてください。

### アイテムの多用途性を意識する
ケイト・グレイのゲームに登場する鍵以外のインベントリアイテムの多くは、2段階の用途を持っています。例えば吊るしワイヤーは、最初にフック状に曲げてジェイコブのベルトから鍵をスリ取るために使われますが、その後も持ち物に残り、ブリキのカップやメガネを引き寄せるためにも使われます。持ち物リストから完全に消滅するまでは、一度使ったアイテムでも油断せず用途を考えましょう。

### フォントや文字色に注目する
開発者は暗号の手がかりを示すために、太字、大文字、色付きのテキストをよく使用します。留置所の掲示板では、**HANDS**、**ITEMS**、**SHIRTS**、**SHOES**、**MOUTHS**といった単語が通常の文章とは視覚的に区別されています。会話や看板に特徴的な書式がある場合は、何らかの暗号の変数になっている可能性が非常に高いです。

## よくある質問（FAQ）

### チャプター3のOn Thin Iceのロッカー暗証番号は何ですか？
正確な**On Thin Iceのロッカー暗証番号**は **40242** です。これは、囚人1名と許可された面会者1名の計2名における、手（4）、持ち込み可能アイテム（0）、シャツ（2）、靴（4）、口（2）の数を順に並べたものです。

### ロッカーのキーパッドに数字が入力できないのはなぜですか？
キーパッドの表面を綺麗にするまで数字を入力することはできません。留置室通路の棚からハンドサニタイザー（消毒液）を入手し、汚れたロッカーの鍵に直接使用してください。綺麗になれば入力できるようになります。

### ジェイコブから留置室の鍵を手に入れるにはどうすればいいですか？
ジェイコブに直接話しかけて鍵をもらうことはできません。壁にある額入りの面会規則を落としてワイヤーを手に入れます。持ち物のワイヤーを使い、ジェイコブが背を向けている隙にベルトループから鍵束を静かに釣り上げてください。

### ロッカーを開けてダンを起こした後、ダンのベルトはどうすればいいですか？
ブリキのマグカップの水でダンを起こし、メガネを返すと、彼は自分の革ベルトを渡してくれます。持ち物にあるベルトを選択して詳しく調べます。バックルをタップして隠しポケットをスライドさせると、クローゼットの鍵が手に入ります。
