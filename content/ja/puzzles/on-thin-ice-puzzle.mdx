## 「On Thin Ice」パズルの仕組みと論理の概要

『Adventure Escape Mysteries』のチャレンジは、状況に応じた環境ストーリーテリングを中心に構築されています。単なる脈絡のない謎解きをこなすのではなく、科学捜査の証拠を収集し、電子セキュリティを突破し、猛吹雪によって生じた物理的な障害物を排除していくことになります。各パズルは、隠されたタトゥーのパターン認識から機械の修理解析まで、それぞれ異なる認知スキルを試してきます。

複雑な複数ステップの操作に取りかかる前に、まずは画面上のインタラクティブなアイテムをくまなく調べることが重要です。錆びついた南京錠に潤滑油を塗ったり、雪解け水で布を湿らせて汚れた表面を拭き取ったりと、事前に準備を要するアイテムも少なくありません。周囲の状況から得られる手がかりを見落として先を急ぐことこそが、行き詰まってしまう最大の原因です。

| パズルのカテゴリ | 必要とされる主なスキル | 障害物の例 | 主な目的 |
| :--- | :--- | :--- | :--- |
| **環境コード** | 観察とカウント | ハックソーのタトゥー金庫 | タトゥーのカウント数を照合してロックされた収納を開ける |
| **機械的配置** | 順序の論理 | 外壁の数字ボード | 外れた金属プレートを正しい位置にはめ込み、山小屋の暗号を特定する |
| **空間スライド** | バッファスロットの管理 | 氷の階段の障害物 | 番号付きの氷ブロックを降順に並べ替える |
| **回路ルーティング** | 回転予測 | キャビネットの三角形グリッド | 回転タイルを経由して端子ノードまで電流を導く |
| **アイテム修復** | インベントリの相乗効果 | 除雪機と車椅子 | 不足している機械部品を組み合わせて塞がれた通路を確保する |

これらのカテゴリごとの特性を把握しておくだけで、無駄な試行錯誤を劇的に減らすことができます。見慣れない **On Thin Ice パズル** に直面した際は、一旦立ち止まり、その場面が暗号の推論、空間の再配置、あるいは事前のインベントリアイテムの使用を求めているのかを見極めましょう。

## キーパッドと暗号パズルのステップ別解法

暗号ロックとテンキー入力は、捜査の初期段階における最初の関門となります。これらのチャレンジでは、小道具、電子画面、あるいは現場に残された被害者など、目に見える場所に手がかりが巧みに潜んでいます。

```
キーパッド入力の流れ:
[周辺の手がかりを調査] ➔ [強調箇所・タトゥーのマークを特定] ➔ [出現回数をカウント] ➔ [コードを入力]
```

### 警察署PCのランサムウェアロック

捜査の開始直後、警察署のローカルネットワークがランサムウェア攻撃を受け、ケイトのデスクは規制線テープで立ち入り制限されます。

1. デスクに隣接する保管ボックス内にある独立したチップリーダーを見つけます。
2. チップリーダーをデスクのインターフェースに直接接続し、モニターを起動します。
3. リーダー本体のハウジングにエンボス加工されている5つの数字 **63849** を確認します。
4. この5桁の数字をコンピュータ画面に入力し、ロックアウトプロトコルを解除します。

### 山小屋の外壁キーパッド

人里離れた山小屋の隠れ家に到着すると、情報屋ハックソー（Hacksaw）への通路が深い雪で塞がれています。予備のホイール、ノズル、燃料キャニスターを使って除雪機を組み立て、吹きだまりを除雪すると、捨てられた金属製の数字プレートが現れます。

1. 除雪した雪山から散らばった金属製の数字プレートを拾い集めます。
2. 入口の右側にある取り付けボードに数字を配置します。
3. 上段に沿って数字を並べ替え、有効な番地シーケンス **40827** を導き出します。
4. 山小屋のデジタルキーパッドをタップし、**40827** を入力してデッドボルトを解錠します。

### ハックソーのタトゥー金庫の暗証番号

山小屋の内部で、金切りのこぎりを使って床板を剥がすと、血痕の付いた金庫が現れます。暗証番号を割り出すには、外の水たまりで布カーテンを濡らし、金庫の扉を綺麗に拭き取る必要があります。発見したシンボル一覧と、死亡した情報屋のタトゥーを照合しましょう。

| 一覧のシンボル | 身体の部位の手がかり | 合計カウント数 | コードの数字 |
| :--- | :--- | :--- | :--- |
| **矢印** | 前腕、指の関節、首、胴体のマーキング | 9 | **9** |
| **ドクロ** | 肩のパッチ、上腕二頭筋、背中 | 4 | **4** |
| **ハート** | 左手首に1箇所のみ | 1 | **1** |
| **波** | 下肢（足・脚部）の帯状パターン | 6 | **6** |

**9416** と入力すると金庫が開き、重要捜査ファイル、三角形タイル、そして第2の中庭に侵入するために必要な特殊ロックピストル（Lockpin gun）を入手できます。

## 氷の階段スライドブロックパズルをマスターする

山小屋裏の出口の先には、重要な証拠を残したまま炎上している車両があります。車両へ到達するには、ひび割れた氷の斜面を降りなければなりません。このセクションで登場するスライドブロック式の **On Thin Ice パズル** では、限られたスロット内で番号の付いた氷の段を降順に整理する必要があります。

```
目標の配置:
[スロット1] ➔ [スロット2] ➔ [スロット3] ➔ [スロット4] ➔ [スロット5]
(ルートに沿った最も低い標高から高い標高へ)
```

このパズルには、一時的な待機スペースとして機能する2つの「保持スロット」が用意されています。このスライド手順を解くコツは、小さなブロックの後ろに大きな数字のブロックを閉じ込めないようバッファスペースを活用することです。

| フェーズ | 戦略的焦点 | 陥りがちな失敗 | 推奨されるアクション |
| :--- | :--- | :--- | :--- |
| **フェーズ1：下段ルートの解放** | 任意の高いブロックを上方へ移動 | 下段スロットを適当なタイルで埋めてしまう | 大きなブロックをすぐに上段の待機スロットへ移す |
| **フェーズ2：アンカーの確立** | ブロック1とブロック2の位置決め | 出口ルートを塞いでしまう | まずブロック1を指定の下部スロットへスライドさせる |
| **フェーズ3：バッファの循環** | ブロック3から5を入れ替え | バッファルートを詰まらせてしまう | アンカーを崩さずに横移動を利用してタイルを循環させる |
| **フェーズ4：最終的な降順ロック** | ブロックを順番に落とし込む | ブロック5の下にブロック4を閉じ込めてしまう | スロット番号が標高ラインと正しく一致しているか確認する |

プレイヤーコミュニティの報告でも、最下部のアンカーブロックを固定する前に中間セクションを揃えようとすると手詰まりになりやすいことが指摘されています。もしブロックの配置が収拾のつかない状態になってしまったら、一度リセットして初期レイアウトに戻し、最初から整理し直すのが確実です。

## 「Triangulate（三角形）」回路パズルの攻略

初期捜査のクライマックスとなるのが、山小屋内にあるキャビネットの回路基板です。この複雑な **On Thin Ice パズル** に着手する前に、敷地内に散らばっている不足した三角形ノードをすべて回収しなければなりません。

### 三角形ピース収集チェックリスト

| 入手場所 | 必要な前提条件 | 獲得アイテム |
| :--- | :--- | :--- |
| **床下の金庫** | 濡れた布 ＋ タトゥーの暗号（`9416`） | 三角形セットA ＋ 手紙 |
| **屋外の金属ボックス** | 潤滑油 ＋ 車椅子のレンチ ＋ 小さな鍵 | 三角形セットB ＋ ドライバー |
| **山小屋前の郵便受け** | 充電済みスマートフォン ＋ 顔認証解除 | 三角形セットC ＋ 参照チャート |

### 回転の仕組みと電流ルーティング

集めたピースをすべて壁のキャビネットにはめ込むと、Triangulateのグリッドが起動します。目的は、パルス状の電荷を開始ノードから右端にある黄色のターゲット三角形まで誘導することです。

* **時計回りの回転:** 電荷が三角形に乗るたびに、そのノードは時計回りに90度回転します。
* **指向性プリズム:** ノードには開放された伝導路と反射エッジがあります。整列していないプリズムに進入すると電流が途切れ、パルスはスタート地点にリセットされます。
* **ルートの先読み:** 着地したノードが*次回*の通過時にどのように向きを変えるかを予測し、常に2手先を読んで計画を立てる必要があります。

開発元のその他のミステリーアドベンチャー作品をチェックしたい場合は、[Haiku Games 公式ポータル](https://www.haikugames.com/)でリリース情報やシリーズの時系列を確認できます。

ハイライトされた経路のノードを順番にタップし、各ピースの強制回転を利用して出力チャンネルを隣接するタイルに合わせます。電流が黄色の三角形への最後のギャップを繋ぐと収納部が開き、ハックソーが隠していた写真のネガが現れます。

## 『Adventure Escape Mysteries』必須の捜査ストラテジー

複雑なポイント＆クリック系ゲームを進めるには、系統だったアプローチが欠かせません。デジタル暗号を解読する場合でも、精巧な仕掛けが絡む **On Thin Ice パズル** に取り組む場合でも、脱出アドベンチャーの定石を守ることで無駄な行き詰まりを防ぐことができます。

* **アイテムの詳細を拡大表示で調べる:** インベントリ内のアイテムの多くに二次的な手がかりが隠されています。たとえば、ハックソーの義足を拡大して調べると、精密ドライバーが必要な隠しパネルが見つかります。
* **周囲の不自然な点を見逃さない:** 不自然な引っかき傷、奇妙なペンキの飛び散り、歪んで掛けられた壁飾りなどは、単なる装飾であることは滅多にありません。ほぼ必ず隠し収納の場所や数字の順序を示しています。
* **スターの消費を節約する:** 『Adventure Escape Mysteries』では、購入しない限りヒントスターの数に限りがあります。手数制限があるパズルや、総当たりが通用しない高度な空間パズルなど、終盤の難問のためにスターを温存しておきましょう。
* **スマホのスクリーンショットを活用する:** タトゥーの数や配線の色を紙にメモしたり、素早くスクリーンショットを撮っておくだけで、複数の部屋を行き来する移動時間を大幅に節約できます。

プレイヤーの経験則として、パズルの不具合と思える現象の8割以上は「前の部屋でアイテムを取り逃していること」が原因です。インタラクティブなボードが反応しない場合は、インベントリを開き、必要な前提アイテムが完全に組み合わされ、適切に使用されているか再確認してください。

## 「On Thin Ice」パズルに関するよくある質問（FAQ）

### 山小屋の中にある金庫の暗証番号はどうやって見つけますか？
金庫の暗証番号は、情報屋ハックソーのタトゥーから割り出せます。金切りのこぎりで緩んだ床板を外し、濡れた布で金庫を綺麗にした後、彼の手の近くにあるシンボル一覧を確認してください。彼の体全体にある各シンボルの合計数を数えます（矢印9個、ドクロ4個、ハート1個、波6個）。コード **9416** を入力すると金庫の扉が開きます。

### 氷の階段パズルをリセットせずに解くコツはありますか？
氷の階段スライドパズルのポイントは、上部にある2つのバッファスペースを長期間の保管場所としてではなく、あくまで一時的な待避場所として使うことです。常に一番小さい番号のステップ（1と2）を最初に空けて正しい位置に配置してください。ベースのステップが正しいレーンに固定されたら、残りの3つのタイルを上部のループで循環させ、降順になるよう落とし込みます。

### キャビネットのTriangulateパズルが開かない・動かないのはなぜですか？
キャビネットのパズルを操作できない場合、必要な3つの三角形セットのいずれかが不足しています。床下の金庫を開けて「セット1」を、車椅子から入手した小さな鍵を使って屋外の錆びた金属ボックスを開けて「セット2」を、ハックソーの顔認証でロック解除したスマホを使って道路脇の郵便受けを開けて「セット3」をそれぞれ入手する必要があります。回路をアクティブにするには、すべてのセットをボード上に配置しなければなりません。

### 『Adventure Escape Mysteries』ではミニゲームをスキップできますか？
はい。どうしてもパズルで行き詰まってしまった場合は、ゲーム内スターを消費することでパズルを完全にスキップすることが可能です。ただし、本ガイドで解説したステップ別の攻略法を活用すれば、パズルが格段に難しくなる後半のチャプターのためにスターをしっかりと温存できます。
