## 薄氷 第2章の概要と主な目的

第2章では、混乱を極めた警察署から一転して、綿密な企業への潜入調査へと舞台が移ります。**薄氷（on thin ice）第2章**における主な目的は、オフィスビル内でサラ・スティコフスキーを追い詰め、回収したハードドライブの証拠を突きつけて問い詰め、彼女が突然逃亡した後にその個人オフィスを捜索することです。

## ロビーへの潜入：ロビーボットの回避と修理

サラ・スティコフスキーのオフィスビルに到着すると、ロビーボットに入場を阻まれ、いきなり壁にぶち当たります。この受付ロボットをなんとかしない限り、重役用エレベーターへ行くことはできません。

### ステップ1：彫刻の落下を引き起こす
ロビーに入ったら、奥の壁際にある観葉植物を調べます。植物を横にスライドさせると、隠された壁のスイッチが現れます。このスイッチを入れると天井から吊るされた現代アートのモビールがバランスを崩し、タイル張りの床に落下して粉々になります。破片の中から鋭利な**彫刻の破片**を拾いましょう。

### ステップ2：記号付き暗証ボックスの解錠
ロビーボットに近づき、4つの会話選択肢をすべて聞いてみます。そのうち3つの返答には、大文字で位置を示すヒントが含まれています：**FIRST（最初）**、**CENTRAL（中央）**、**LAST（最後）**。

* 最初のヒント（FIRST）に対応する記号を確認します。
* 中央のヒント（CENTRAL）に対応する記号を確認します。
* 最後のヒント（LAST）に対応する記号を確認します。

ロビーの壁に取り付けられている施錠されたセキュリティボックスを調べます。太字の会話の手がかりで示された3つの記号に合うように、3つのダイヤルを回転させます。ボックスを開くと、巻かれた**銅線**が手に入ります。

### ステップ3：アトリウムからの部品回収
ロビーボットに銅線を巻き付けると、電気的な過負荷が発生してショートします。隣の装飾植物を横にスライドさせると、隠されたメンテナンスハッチが現れます。**彫刻の破片**をバール代わりに使って隙間に差し込み、扉をこじ開けましょう。

メンテナンス用クローゼットの中から**脚立**を回収し、道具箱を開けて**ドライバー**を取ります。次に以下の作業を行います：
1. 頭上の蛍光灯の真下に脚立を置きます。
2. 天井の照明器具の中に手を伸ばし、**フラッシュコンデンサ**を取り外します。
3. 壁の配電ボックスにドライバーを使い、**照明スイッチ**を取り外します。

| 回収したアイテム | 入手場所 | 直後の使い道 |
| :--- | :--- | :--- |
| **彫刻の破片** | 壊れた天井のモビール | 隠されたメンテナンスハッチをこじ開ける |
| **銅線** | 3つの記号のロビー金庫 | ロビーボットに巻き付けてショートさせる |
| **ドライバー** | メンテナンス用クローゼットの工具箱 | 壁面の照明スイッチを取り外す |
| **脚立** | メンテナンス用クローゼット | 高所にある照明器具に手を届かせる |
| **フラッシュコンデンサ** | 頭上の照明器具 | 過負荷回路の組み立てに使用 |

### ステップ4：ロビーボットの回路再プログラミング
フラッシュコンデンサと照明スイッチを、ロビーボットのむき出しになった配線に取り付けます。スイッチを入れます。発生したサージ電流によってユニット内部の処理ボードが破壊され、**コンピューターチップ**が床に落ちます。これらのチップをロビーボットのアクセスパネルにはめ込み、チップ配置のミニゲームを開始します。

再プログラミングパズルを解くには、隣接する回路の接続ラインがすべての共有する辺で完全に一致するように、各チップを内部グリッド上に配置します。まずは2面しか接続部のない四隅のチップを特定して角から埋めていき、そこから中央のノードに向かって埋めていくのがコツです。色や線の不一致なしにすべてのノードがつながると、ロビーボットは従順なモードで再起動し、エレベーターの利用を許可してくれます。

## スティックスとの対峙：会話の戦略と煙の排出

**薄氷（on thin ice）第2章**で重役室に足を踏み入れたケイトは、計算高い態度を演じる必要があります。サラ・スティコフスキーは人質交渉や企業交渉のプロです。もしケイトが高圧的に詰め寄れば、スティックスは即座に口を閉ざしてしまうでしょう。

```
[ロビー突破] ➔ [重役室へ侵入] ➔ [不満を漏らす会話を選択] 
       ➔ [ハックソーの証拠を提示] ➔ [内心の思考でブラフ] 
       ➔ [発煙筒が作動] ➔ [扇風機で煙を排出]
```

### 尋問の進め方
デスクにいるスティックスに近づきます。彼女の警戒を解くため、令状を執行しに来た警察官ではなく、報酬を求めてやってきた不満だらけの公務員であると信じ込ませます。

以下の順番で正確に会話を選択してください：
1. **「私たちは一度も報酬をもらえない。」（"We never get a reward."）**（人間には誰にでも値段があるという彼女の信条を突きます）。
2. **「ハックソーの証拠を持っている。」（"I have Hacksaw's evidence."）**（組織に関する切り札を握っていることを証明します）。
3. デスクの上に**ハードドライブ**を置きます。
4. 内心の反応を求められたら、**（夕食のことを考える）- (think about dinner)** を選択します。

この平然とした態度は、スティックスの行動プロファイリングを完全に狂わせます。出し抜かれたと悟った彼女は、非常用発煙筒を炸裂させて施設内へと逃亡します。

| 会話の選択肢 | 成功する理由 | 失敗時の結果 |
| :--- | :--- | :--- |
| *「私たちは一度も報酬をもらえない。」* | 警察は買収可能であるという彼女の冷笑的な世界観に合わせるため。 | 攻撃的な脅しを選ぶと、早期に防犯プロトコルを作動させてしまう。 |
| *「ハックソーの証拠を持っている。」* | 第1章の出来事に関連した、具体的な交渉材料を確立するため。 | 証拠を出し渋ると、会話を打ち切られてしまう。 |
| *（夕食のことを考える）* | 緊張の微細な表情を防ぎ、ケイトの本心を完全に隠すため。 | 緊張や敵意のある考えを選ぶと、即座に逃亡されてしまう。 |

### 重役室の換気
濃く立ち込める煙がオフィスを覆い、詳細な捜査ができません。重いデスクチェアを邪魔にならないよう角のコンセントの方へ引きずって移動させます。**扇風機**を拾い、窓際の通路近くに置いて電源コードを壁のコンセントに差し込みます。強力な扇風機が部屋の煙を吹き飛ばし、床や家具の上に散らばった手がかりが姿を現します。

煙が晴れた部屋から以下のアイテムを回収します：
* 放置された**ハードドライブ**（鑑識分析のためペニーが保管します）。
* サイドチェストの近くに落ちている小さな**人形**。
* 追加の**扇風機の部品**と装飾用の**本棚の置物**。
* カーテンの留め具から回収する頑丈な編み込みの**カーテンのロープ**。
* 強力な**ダクトテープ**のロール。

## 本棚パズル：ポラロイド写真の手がかりとアイテムの配置

**薄氷（on thin ice）第2章**のクライマックスは、スティックスの私的な壁面アーカイブの解錠です。表向きのオフィスの裏には巧妙に配置された棚があり、そこに個人的な通信記録や追跡記録が隠されています。

開発元によるパズル作品の一覧や登場キャラクターの詳細は、公式の[Haiku Games studio library](https://www.haikugames.com/)でシリーズの詳細な設定を確認できます。

### ステップ1：シャンデリアの鍵の入手と金庫の解錠
天井の照明を見上げます。シャンデリアのチェーンに小さな鍵が引っかかって光っていますが、手では届きません。インベントリのアイテムを組み合わせて手に入れましょう：
1. **ダクトテープ**を使ってフロアランプの擦り切れた電気コードを修理し、天井を安全に照らして調べられるようにします。
2. **カーテンのロープ**を選び、シャンデリアに向かって投げ上げて引っ掛け、**金庫の鍵**を引き下ろします。
3. 肖像画の裏に隠されている壁の金庫に鍵を使って解錠します。

金庫の中から、一束の**ポラロイド写真**を回収します。

### ステップ2：見つからないプレートの捜索
インベントリ内で手に入れたばかりのポラロイド写真を調べます。写真をめくっていく際、背景の細部に注目してください。1枚の写真には怯えた少女が写っており、別の写真には金庫の蝶番の裏に隠された細長い金属製の**クランプ**が写っています。クランプを入手しましょう。

大きな本棚の一番下の幅木付近を調べます。下の棚の狭い隙間に、装飾用の金属製受賞プレートが落ちています。クランプを使って**落ちたプレート**を引き出します。これで、メインの本棚パズルに挑むために必要な展示品がすべて揃いました。

| 必要なアイテム | 入手方法 | 本棚での最終的な役割 |
| :--- | :--- | :--- |
| **磁器の人形** | 煙が晴れた後、サイドチェスト上で発見 | 子供時代の写真に従って配置する |
| **真鍮のプレート** | クランプを使って棚の下から引き出す | 一致する年代のトロフィーの下に取り付ける |
| **本棚の置物** | 床やオフィスのデスクから回収 | 見た目の高さに基づいて棚ごとにバランスよく配置 |
| **デスクランプ** | ダクトテープで修理して点灯 | 特定の棚の区画を照らし出す |
| **ポラロイド写真のセット** | シャンデリアの鍵で壁の金庫から開錠 | 全体の配置を決めるための設計図となる |

### ステップ3：本棚の配置の謎解き
置物、人形、プレートを、何段にも分かれた本棚の空いているスロットに配置します。ポラロイド写真を開き、スティックスが以前どのように私物を並べていたかを参照します。

各写真の視覚的な特徴に細心の注意を払いましょう：
* **トロフィーの棚**：トロフィーは大きさ順ではなく、写真で確認できる刻印された年代順に並べる必要があります。
* **私物**：少女の写真で革装丁の日記の隣に置かれているのと同じ特定の棚に、人形を配置します。
* **対称的な置物**：抽象的な幾何学模様の置物は、重役室の記録写真に写っている鏡面対称のパターンと一致させる必要があります。

すべての置物、小像、プレートがかつてあった通りの正しい位置に収まると、壁のパネル内にある隠された機械式ラッチがカチリと音を立てて開きます。

## コミュニティのヒントとトラブルシューティング

コミュニティフォーラムに寄せられたプレイヤーの体験談から、本章で詰まりやすいポイントをいくつか紹介します。進行に行き詰まった場合は、以下のヒントを確認してみてください：

* **隠しパネルが反応しない**：受付ロビーで、2つ目の観葉植物を動かさずに隠し扉をタップしてしまうケースがよく見られます。壁のスイッチもメンテナンスハッチも、先に装飾用の植物をどかす必要があります。
* **再プログラミングのグリッドで行き詰まる**：回路の線がうまく繋がらない場合は、外周のチップを確認してください。3方向に接続部があるチップを外側の端に配置してしまい、1つの端子が壁に向かって無駄になってしまっているミスが多く見られます。
* **クランプが見つからない**：落ちたプレートを取るためのクランプが見つからない場合は、インベントリをもう一度開き、ポラロイド写真をタップしてめくってみてください。クランプは金庫の壁の中ではなく、重なった写真の裏側に物理的に隠されています。
* **壊れたランプが取れない**：オフィスのサイドテーブルに置かれているデスクランプは、擦り切れた電源コードにダクトテープを使って修理するまで持ち上げることができません。

## よくある質問（FAQ）

### 薄氷 第2章でスティックスと話す際の正しい会話の選択肢は何ですか？
**薄氷（on thin ice）第2章**でサラ・スティコフスキーを警戒させずに話を進めるには、まず「私たちは一度も報酬をもらえない。」（"We never get a reward."）を選び、次に「ハックソーの証拠を持っている。」（"I have Hacksaw's evidence."）を選択します。デスクにハードドライブを置き、内心のモノローグが表示されたら「（夕食のことを考える）- (think about dinner)」を選んでください。この組み合わせにより、彼女が発煙筒を使って逃走する前に、こちらの優位を保つことができます。

### 薄氷 第2章のロビーにある暗証ボックスの組み合わせはどうやって見つけますか？
ロビーボットに話しかけ、用意されている4つの質問をすべて行います。大文字で表記されている**FIRST（最初）**、**CENTRAL（中央）**、**LAST（最後）**の単語が含まれるセリフに注目してください。それぞれの単語が特定の形状と直接結びついています。銅線を入手するために、その正確な順序で3つの形状を3連ダイヤル式ボックスに入力してください。

### オフィスの本棚パズルで足りないプレートはどこにありますか？
真鍮のプレートは、大きな本棚の一番下の隙間に落ちています。素手で届く場所にはありません。インベントリを開き、金庫から回収したポラロイド写真を調べて、写真の隙間に隠されている小さな金属製のクランプを回収してください。そのクランプを本棚の下の隙間に使うことで、プレートを取り出すことができます。

### 重役室の扇風機が動かないのはなぜですか？
扇風機を作動させるには2つの手順が必要です。まず、大きなオフィスチェアを引きずって移動させ、隠れていた壁のコンセントを露出させます。次に扇風機を拾い、出入口の通路近くの床に置いて、電源コードを露出したコンセントに直接差し込みます。電源が入ると、扇風機は自動的に煙幕を吹き飛ばしてくれます。
