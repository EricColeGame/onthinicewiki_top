## 警察署の端末突破とキャビンへの侵入

捜査は、黄色い立入禁止テープが張られた警察署内、サイバー攻撃でロックされたケイトの作業デスクから始まります。このオープニングシーンで極秘情報を引き出し、情報屋ハックソーの隠れ家へと急行しなければなりません。

### ステップ1：警察署PCのロック解除
1. ケイトの封鎖されたデスク付近にある備品箱を調べ、**チップリーダー**を入手します。
2. チップリーダーを端末横のPCデスクの上に置きます。
3. モニター画面に5桁のハードウェア認証キーが要求されているのを確認します。
4. チップリーダー本体のケースを調べます。太字でくっきりと印字された5桁の数字 **63849** が確認できます。
5. デスクトップのキーボードに **63849** と入力し、ランサムウェアのバリアを突破して捜査ファイルをアンロックします。

```
正確なポイント：インベントリ内や拡大視点で、物理的な小道具を隅々まで調べる習慣をつけましょう。Haiku Gamesでは、ハードウェアのラベルにパスコードが直接印字されていることがよくあります。
```

### ステップ2：雪の除去とキャビンへの侵入
人里離れたキャビンに到着すると、ケイトとマーフィーは直前まで銃撃戦が行われていた痕跡を発見します。情報屋ハックソーは室内で反応がなく、深い雪が正面玄関を塞いでいます。

* 敷地内を探索し、除雪機に不足している3つのパーツ（**車輪**、**排雪シュートノズル**、**燃料缶**）を回収します。
* 私道の脇に放置されている除雪機にパーツを取り付けます。
* 除雪機を動かして分厚い雪山を取り除き、正面ポーチの階段への通路を確保します。
* 私道の雪の下から現れた、散らばった**金属の数字**を拾い集めます。
* 正面入口の右側にある掲示板に近づき、金属の数字を配置します。一番上の数列を正しく並べ替えると、ドアのパスコード **40827** が導き出されます。
* キャビンのドアにあるテンキーに **40827** と入力し、中に入ります。

| 入力場所 | 目的 / 手がかりの出所 | 解答コード |
| :--- | :--- | :--- |
| **警察署の端末** | チップリーダー本体の太字番号 | **63849** |
| **キャビンポーチのテンキー** | 屋外掲示板の並べ替えた金属数字 | **40827** |
| **床下金庫のダイヤル** | ハックソーの遺体にあるタトゥー記号の合計数 | **9416** |

これらの初期パズルを手際よく解決することで、**『On Thin Ice』第1章**のテンポを崩さず、亡くなった情報屋のキャビンへ入る前に重要なツールを確実に揃えることができます。

## ハックソーのキャビン捜査：床板、タトゥー、そして金庫

薄暗いキャビンの中で、ケイトとマーフィーはハックソーの遺体を発見します。情報屋は二人が到着する直前に殺害されており、犯人がまだ近くに潜んでいる可能性を示唆しています。

### キャビン内のアイテム回収と床下金庫の露出
1. 乱れたマットレスを壁から引き離し、床のラグを巻き上げます。
2. 木製の雨戸を開けて自然光を取り込み、犯行現場を照らします。
3. 窓の横に掛かっている**布のカーテン**を取り外します。
4. 壁上部のキャビネットを開けると、未完成の電気パズル装置が見つかります。そこから**のこぎり**を入手します。
5. ラグの下から現れた緩んだ床板へ向かいます。のこぎりを使って継ぎ目を切り開き、重い鉄製の金庫を持ち上げます。

### タトゥー記号金庫の暗号解読
床下の金庫は、ダイヤルの目盛りに血痕がこびりついているため、すぐには開けられません。

* 外の正面ポーチに出て、水たまりに布のカーテンを浸して**濡れた布**を作ります。
* 部屋に戻り、金庫のフタについた血痕を拭き取ります。ダイヤルの上部には、**矢、ドクロ、ハート、波**の4つのアイコンが刻まれています。
* ハックソーの手元にある記号が書かれた紙片を拾います。
* ハックソーの遺体を首、腕、胴体、脚の4箇所に分けて詳しく調べます。彼の肌にこれらの特定のタトゥーデザインがいくつ彫られているかを数えます。

| 記号アイコン | 遺体のタトゥー数 | コードの位置 |
| :--- | :--- | :--- |
| **矢** | 腕と胴体全体で計9回出現 | 1桁目：**9** |
| **ドクロ** | 肩と胸部で計4回出現 | 2桁目：**4** |
| **ハート** | 手首の近くに1回出現 | 3桁目：**1** |
| **波** | 前腕と首筋に沿って計6回出現 | 4桁目：**6** |

金庫のダイヤルに **9416** と入力します。開いたら、**事件の手紙**、最初の**三角形ピース**、そして**ピックガン**を回収します。

## 裏庭の攻略：氷の階段と炎上した車

ピックガンを手に入れたら、キャビンの右側の壁にある頑丈な補強ドアを解錠し、凍りついた裏庭へ出ます。外には待ち伏せの際に破壊された車両が煙を上げています。

```
戦術のヒント：飛び石（氷塊）の位置合わせパズルを解く前に、凍った渓谷を渡ろうとしないでください。整列していない氷の上に足を踏み入れると、ルートがリセットされてしまいます。
```

### 裏庭の障害物ルートの攻略
1. 裏庭のBBQグリルのキャンバスタープをめくり、**消火器**と**潤滑油（クリーニングオイル）**を見つけます。
2. フェンス近くの地面の雪を払い、錆びた金属のボックスを露出させます。潤滑油を塗布して表面のサビを溶かし、後で鍵が見つかったときに鍵穴が回るように準備しておきます。
3. 渓谷にかかる割れた氷の塊をタップして、**氷の階段パズル**を開始します。

### 氷の階段スライドパズル
氷の階段パズルの目的は、番号の付いた氷のブロックをグリッド上でスライドさせ、各ブロックを対応する番号のスロットに収めることです。
* クラシックなスライディングパズルの要領で進めます。本命の経路ブロックを正しい位置に動かす間、外周の空きスペースを一時的な退避場所として活用します。
* 手前の足場から車のある岸に向かって、数字が昇順になるようにブロックを配置します。
* 通路がしっかりと固定されたら、消火器を構えて渓谷を渡ります。

### 車両と犠牲者の調査
* 燃えているセダンに消火器を使用し、炎を完全に消し止めます。
* 車の周囲に倒れている犠牲者を調べ、**バール**と**レンチ**を回収します。
* 挟まって動かない車のドア枠にバールを差し込んでこじ開け、グローブボックス内にある巻き取られた**電話コード**を入手します。

## データの抽出：携帯電話と三角形パズル

新たな道具を持ってキャビン内に戻ると、ハックソーの隠しコンパートメントを開け、損傷した通信デバイスを充電できるようになります。

```
インベントリの連携手順：
- 電話コード -> 室内の壁コンセントに接続
- レンチ -> 壊れた車椅子の車軸を修理して小さな鍵を外す
- 小さな鍵 -> 裏庭の錆びた保管ボックスを開ける
- ドライバー -> ハックソーの義足を開ける
```

### バッテリー切れの携帯電話を入手する
1. キャビン内に戻り、デスクの充電パッドの横にある壁コンセントに電話コードを差し込みます。
2. 部屋の隅に置かれた車椅子を調べます。レンチを使ってホイールアセンブリの固いボルトを緩め、**小さな鍵**を取り外します。
3. 裏庭に戻り、サビを落とした保管ボックスに小さな鍵を差し込みます。**ドライバー**と2つ目の**三角形ピース**を入手します。
4. ハックソーの遺体に戻ります。ドライバーを使って義足のコンパートメントパネルを開け、彼の私物である**電源の切れた携帯電話**を取り出します。
5. 接続したワイヤレス充電パッドの上に電話を置きます。バッテリーが必要な残量に達するまで、ケイトとマーフィーの会話を進めます。

### 顔認証の突破と郵便ポストの解錠
* 携帯電話の電源が入りますが、生体認証（Face ID）でロックされています。端末を持ち上げ、ハックソーの顔の前にかざしてセンサーを反応させます。
* 未読のSMSスレッドを読みます。ハックソーが何者かに脅迫されていたこと、そして至急の配達物が正面の郵便ポストに届けられたことが判明します。
* 正面の私道に出て、ロックを解除した携帯電話を使用して郵便ポストのスマートロックを解除します。
* 3つ目の最後の**三角形ピース**と、暗号の**チャート**を回収します。

| パズル段階 | 必要なアイテム | アンロックされるアイテム |
| :--- | :--- | :--- |
| **車椅子の修理** | レンチ | 小さな鍵 |
| **裏庭の保管ボックス** | 小さな鍵 ＋ 潤滑油 | ドライバー ＋ 三角形ピース |
| **義足の収納部** | ドライバー | ハックソーの携帯電話 |
| **正面のスマートポスト** | ロック解除済み携帯（Face ID） | 三角形ピース ＋ 暗号チャート |
| **キャビネットの三角形パズル** | 三角形ピース3セット | 犯行現場の写真 |
| **壁の隠し金庫** | 手紙 ＋ チャート ＋ 写真 | 暗号化されたハードドライブ |

### キャビネットの三角形パズルを解く
キャビン内に戻り、壁のキャビネット内にある未完成のパズルを拡大します。集めたすべての三角形タイルを開いている枠内に配置します。

1. **パズルの目的：** スタート地点のノードから、右端にある明るい黄色の受信三角形まで電流を導きます。
2. **回転ルール：** 電流パルスが三角形タイルを通過するたびに、そのタイルは時計回りに90度自動回転します。
3. **攻略法：** パルスが跳ね返って行き止まりに戻らないような回転位置を逆算してルートを計画します。電流を流す前に、右側のゴールへ向かう開放された進路を作ることに集中しましょう。
4. **クリア結果：** 回路が完成すると装置が開き、極めて重要な**犯行現場の写真**が現れます。

### ハードドライブの発見
キャビンの壁板の印がついた場所に近づきます。**事件の手紙**、**暗号チャート**、そして**犯行現場の写真**をボードに貼り付けます。

交差する座標を合わせると隠し壁金庫が現れ、その中からハックソーのマスター**ハードドライブ**が見つかります。このドライブを確保したことで、ケイトとマーフィーは陰謀を暴くための決定的な証拠を手に入れ、**『On Thin Ice』第1章**はスリリングな結末を迎えます。

## よくある質問（FAQ）

### 『On Thin Ice』第1章のキャビン内にある金庫の暗証コードは何ですか？
**『On Thin Ice』第1章**で緩んだ床板の下に隠されている金庫のコードは **9416** です。濡れたカーテン布で金庫のフタの血痕を拭き取ると、「矢、ドクロ、ハート、波」の4つの記号が現れます。ハックソーの遺体にある該当するタトゥーを数えると、矢が9個、ドクロが4個、ハートが1個、波が6個となります。

### 充電後、ハックソーの携帯電話のロックはどうやって解除しますか？
ワイヤレス充電パッドでハックソーの携帯電話を充電したら、デスクから携帯を取り、ハックソーの遺体の顔に直接かざします。このスマートフォンは生体顔認証（Face ID）を採用しているため、亡くなった情報屋の顔に画面を向けることでロックが解除され、メッセージが読めるようになります。

### 『On Thin Ice』第1章の三角形ピースはどこにありますか？
キャビネットの電気回路パズルを完成させるには、以下の3箇所から三角形ピースを集める必要があります。
1. コード **9416** で開ける床下の金庫の中。
2. 修理した車椅子から手に入れた小さな鍵で開ける、裏庭の錆びた保管ボックスの中。
3. ロック解除した携帯電話を使って開ける、正面私道のスマート郵便ポストの中。

### 『On Thin Ice』第1章で除雪機が動かない場合はどうすればいいですか？
除雪機が動かない場合、雪の積もった私道周辺に散らばっている3つの必須パーツのいずれかが不足しています。周囲を注意深く探索し、交換用の車輪、排雪シュートノズル、赤い燃料缶を回収してください。キャビンのドアを塞ぐ雪山を取り除く前に、これら3つのアイテムすべてを除雪機に取り付ける必要があります。
